# 独自の価値提案（USP）とターゲット層

## OROKAIのUSP

### 設計段階からのノンカストディアル
OROKAIはユーザーの資金を保有しません。ユーザーが署名する取引のオーケストレーションレイヤーとして機能します。

### 一箇所で複数のチェーンとプロトコルに対応
自動化されたアロケーション、クレーム、マイグレーションを備えたDeFi集約。

### AIエージェント
ユーザープロファイル（好み、経験、リスク許容度）に合わせた<mark>情報提供</mark>の推奨。投資助言を構成するものではありません。

### 「ゼロフリクション」UX
オンボーディングプロセスとポジション管理の最大限の簡素化（ライセンス取得済みパートナーによるオン/オフランプサポートを含む）。

### 透明性
プロトコルによって生成される報酬はUSDTで決済される場合があります。その<mark>レベルは変動し、保証されません。</mark>


## ターゲット層

Web3以外の個人（シンプルさ）、暗号資産ユーザー（自動化/最適化）、B2B/B2B2Cパートナー（API/ホワイトレーベル — ノンカストディアルモデル）
