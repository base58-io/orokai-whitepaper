# AI Agent OROKAI

## AIモジュール

AI Agent OROKAIは、選択肢の理解と意思決定の整理において<mark>ユーザーをサポートする</mark>モジュールです。ユーザープロファイル（目標、好み、経験、リスク許容度）と現在の市場パラメータに基づいて、エージェントはユーザーの優先事項に合致した戦略とプロトコルを提案します（助言ではありません）。<mark>エージェントはユーザーに代わって行動しません</mark>： 

>提案と説明を準備します

>すべての取引はユーザーが自身のウォレットで独立して署名します

:::tip[OROKAI AIをGoogle Mapsのように考えてください] 

> Google Mapsは目的地までのルートを表示し、理由を説明します（最短、最速、景色が良い）、交通状況を表示しますが、どのルートを選ぶかを決めるのはあなたであり、車を運転するのもあなたです。
 
> OROKAI AIは3つのDeFi戦略を表示し、理由を説明します（保守的、バランス、積極的）、コスト/リスクを表示しますが、どれを選ぶかを決めるのはあなたであり、取引に署名するのもあなたです。
:::

## モジュールの性質
情報提供のみ。投資、法律、または税務に関する助言を構成するものではありません。リターンは変動し、保証されません。外部プロトコルのパラメータから生じます。

:::warning[情報提供のみ]

AI Agentの推奨は、ユーザーが選択肢をナビゲートするのを支援するために設計されており、投資助言を提供するものではありません。すべての決定と行動は完全にユーザーの管理下に留まります。

:::
