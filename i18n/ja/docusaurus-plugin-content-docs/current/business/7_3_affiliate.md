# アフィリエイトプログラム

## プログラム概要

OROKAIのアフィリエイトプログラムは、暗号資産業界で最も<mark>革新的で寛大な</mark>プログラムの1つであり、以下の特徴があります：

- **マルチレベル収益**（3レベルの深さ：A → B → C）
- **TVLベースのティアシステム**（5ティア：BasicからLegendまで）
- **生涯アトリビューション**（時間制限なし、上限なし）
- **柔軟な配分**（Pro+ティアで戦略を最適化）
- **NFT譲渡可能性**（アフィリエイトビジネスを資産として売却）
- **すべての収益源**（カード、スワップ、ステーキング、ブリッジ、オン/オフランプから収益）

このプログラムは、ノンカストディアル原則を維持しながら、<mark>リクルーターとネットワークビルダーの両方</mark>に報酬を与え、持続可能な成長を促進します。

:::tip[中核哲学]
アフィリエイトはOROKAIの収益（ユーザー資金ではない）のシェアを得ます。プラットフォームが成功すると、私たちは一緒に成長します。ピラミッドスキームではなく、ソフトウェアとサービスを通じた真の価値創造です。
:::

## ティア構造

OROKAIは、単なるリクルーターではなく、アクティブな参加者に報酬を与えるために<mark>TVLベースのティアシステム</mark>を使用します。あなたとあなたのネットワークがOROKAIを通じて管理する資本が多いほど、収益の可能性が高まります。

### 完全なティア内訳

| ティア | TVL範囲 | レベルA（直接） | レベルB（2次） | レベルC（3次） | 合計最大 | 柔軟な配分 |
|------|-----------|------------------|---------------------|---------------------|-----------|---------------------|
| **Basic** | 0～1万ドル | 10% | 0% | 0% | 10% | なし |
| **Premium** | 1万～10万ドル | 15% | 0% | 0% | 15% | なし |
| **Pro** | 10万～100万ドル | 20% | 5% | 0% | 25% | ±2パーセントポイント |
| **VIP** | 100万～1,000万ドル | 22% | 6% | 2% | 30% | ±4パーセントポイント |
| **Legend** | 1,000万ドル以上 | 25% | 10% | 5% | 40% | ±6パーセントポイント |

### レベルA、B、Cとは何を意味するか？

> レベルA：直接紹介（あなたが招待した人々）
> レベルB：間接紹介（あなたの紹介者が招待した人々）
> レベルC：第3レベル紹介（レベルBによって招待された人々）
```
構造例：

あなた（Legendティア）
 │
 ├─ Alice（レベルA - あなたが直接招待）
 │   └─ Bob（レベルB - AliceがBobを招待）
 │       └─ Carol（レベルC - BobがCarolを招待）
 │
 └─ Dave（レベルA - あなたが直接招待）
     └─ Eve（レベルB - DaveがEveを招待）

Carolが取引すると：
├─ Bobがレベルから収益（彼の直接紹介）
├─ Aliceがレベルから収益（彼女のティアが許可する場合）
└─ あなたがレベルから収益（あなたのティアが許可する場合 - Legendは許可！）
```

### 柔軟な配分の説明

**Proティア**から、レベル間のパーセンテージ配分を調整して戦略を最適化できます。

#### Proティア（±2ポイント）：

デフォルト：20%（A）+ 5%（B）= 25%合計

有効な調整：
- 22%（A）+ 3%（B）= 25%（直接募集に焦点）
- 21%（A）+ 4%（B）= 25%
- 19%（A）+ 6%（B）= 25%
- 18%（A）+ 7%（B）= 25%（ネットワーク構築に焦点）

#### VIPティア（±4ポイント）：

デフォルト：22%（A）+ 6%（B）+ 2%（C）= 30%合計

調整例：
- 26%（A）+ 2%（B）+ 2%（C）= 30%（直接に最大焦点）
- 18%（A）+ 10%（B）+ 2%（C）= 30%（ネットワークに力を与える）
- 20%（A）+ 6%（B）+ 4%（C）= 30%（バランス）

#### Legendティア（±6ポイント）：

デフォルト：25%（A）+ 10%（B）+ 5%（C）= 40%合計

調整例：
- 31%（A）+ 4%（B）+ 5%（C）= 40%（募集重視戦略）
- 19%（A）+ 16%（B）+ 5%（C）= 40%（レベルB強化）
- 25%（A）+ 4%（B）+ 11%（C）= 40%（深いネットワーク焦点）

#### なぜこれが重要か：

異なるユーザーのための異なる戦略：
- **インフルエンサー/大規模オーディエンス：** レベルを最大化（数千人を直接募集）
- **コミュニティビルダー：** レベルを強化（あなたの紹介者が優れたリクルーター）
- **ネットワーク効果最大化：** レベルに投資（深さでの指数関数的成長）

変更は**即座**であり、ダッシュボードでいつでも調整できます。

## TVL計算

### ティアの決定方法

あなたのティアは**ロックされた総価値（TVL）**に基づいており、以下が含まれます：

> あなたの総TVL = 
    OROKAIウォレットへのあなた自身の預金の合計と以下のすべて：
>  + レベル預金の100%（直接紹介）
>  + レベル預金の100%（間接紹介）
>  + レベル預金の100%（第3レベル紹介）

計算時点：支払い時（リアルタイムスナップショット）
```
例：

シナリオ：Aliceが自分のティアを知りたい

Alice自身の預金：500,000ドル

Aliceの紹介ネットワーク：
├─ レベル（5人の直接紹介）：
│   └─ Bob：20万ドル、Carol：30万ドル、Dave：10万ドル、Eve：15万ドル、Frank：5万ドル
│   └─ 小計：800,000ドル
│
├─ レベル（AliceのレベルAからの紹介）：
│   └─ Bobが3人を招待：合計40万ドル
│   └─ Carolが2人を招待：合計20万ドル
│   └─ 小計：600,000ドル
│
└─ レベル（AliceのレベルBからの紹介）：
    └─ Bobの紹介者が5人を招待：合計30万ドル
    └─ 小計：300,000ドル

═══════════════════════════════════════════════
AliceのTVL合計：
50万ドル（自分）+ 80万ドル（A）+ 60万ドル（B）+ 30万ドル（C）= 2,200,000ドル

Aliceのティア：VIP（100万～1,000万ドル範囲）
Aliceの収益：22%（A）+ 6%（B）+ 2%（C）= OROKAI手数料の30%

主な洞察：

ネットワーク乗数：Aliceの50万ドルの個人投資がネットワークを通じて220万ドルのTVLになる（4.4倍乗数）

ティアの進行：小額の個人預金でも、強力な募集を通じてLegendティアに到達可能

スナップショットベース：TVLは毎回の支払い時に再計算されるため、ティアは動的に変化可能

注：Aliceの紹介者が資金を引き出すと、彼女のTVLは減少し、ティアが低下する可能性があります（次の支払い時に再計算）
```

## マルチレベルメカニクス

### 収益の流れ方

アフィリエイト構造を通じたお金の流れを理解する：

#### 基本原則：

ユーザーが取引 → OROKAIが手数料を得る → アフィリエイトが収益を共有 → 同じトークンで支払い

#### マルチレベル分配の例：
```
ネットワーク構造：

あなた（Legend：25% A、10% B、5% C）
 │
 └─ Alice（Pro：20% A、5% B）[あなたのレベルA]
     │
     └─ Bob（Premium：15% A）[あなたのレベルB、AliceのレベルA]
         │
         └─ Carol（Basic：10% A）[あなたのレベルC、BobのレベルA、AliceのレベルB]

Carolが10,000 USDC → ETHをスワップ
├─ DEX LP手数料（0.05%）：5ドル
├─ OROKAIルーティング手数料（LPの25%）：1.25ドル
└─ この1.25ドルがアフィリエイト分配に利用可能

誰がいくら得るか：

1. Bob（Carolの直接招待者 - CarolはBobのレベルA）：
   ├─ BobはPremiumティア：15%（Aのみ）
   ├─ Bobの収益：1.25ドル × 15% = 0.1875 USDC

2. Alice（Bobの招待者 - CarolはAliceのレベルB）：
   ├─ AliceはProティア：20%（A）、5%（B）
   ├─ CarolはAliceのBレベル（Aliceから2レベル深い）
   ├─ Aliceの収益：1.25ドル × 5% = 0.0625 USDC

3. あなた（Aliceの招待者 - CarolはあなたのレベルC）：
   ├─ あなたはLegendティア：25%（A）、10%（B）、5%（C）
   ├─ Carolはあなたのレベル（あなたから3レベル深い）
   ├─ あなたの収益：1.25ドル × 5% = 0.0625 USDC

═══════════════════════════════════════════════
アフィリエイト支払い合計：0.1875 + 0.0625 + 0.0625 = 0.3125ドル
OROKAIの保持：1.25 - 0.3125 = 0.9375ドル（75%）

主な観察：

相対位置が重要：Carolは自分にとってレベルA、Aliceにとってレベルは、あなたにとってレベルC

トークンネイティブ支払い：元の手数料がUSDCだったため、USDCで獲得

カスケードにはティアの深さが必要：Pro+ティアのみがマルチレベル構造から利益を得る
```

## 柔軟な配分戦略

**Proティア**から、アフィリエイトはネットワークの特性に基づいて収益を最適化するために、パーセンテージ配分を調整できます。この機能により、ネットワークが進化するにつれて戦略を適応させることができます。

### なぜ柔軟な配分が重要か

異なるアフィリエイトには異なる強みがあります：

> 戦略A：「直接リクルーター」
- 大規模なオーディエンスを持つ（YouTube、Twitter、ポッドキャスト）
- 何百/何千もの直接ユーザーを募集
- あなたの紹介者は自分自身ではあまり募集しない
- **最適な配分：** レベルAのパーセンテージを最大化

> 戦略B：「ネットワークビルダー」
- より少ない人を募集するが、質の高いリクルーター
- あなたの紹介者は自分のネットワークを構築するのが得意
- 指数関数的成長がレベルB/Cで起こる
- **最適な配分：** レベルBまたはCにパーセンテージをシフト

> 戦略C：「バランスの取れた成長」
- 直接募集とネットワーク構築の混合
- デフォルトの配分を維持または軽微な調整
- **最適な配分：** デフォルトの近くに留まるか、データに基づいて調整

### ティア別の配分範囲

#### Proティア（±2パーセントポイント）：
```
デフォルト：20%（A）+ 5%（B）= 25%合計

有効範囲：
├─ レベルA：18% - 22%
└─ レベルB：3% - 7%

例：
- 22% A + 3% B = 25%（リクルーター重視）
- 21% A + 4% B = 25%
- 19% A + 6% B = 25%
- 18% A + 7% B = 25%（ネットワーク重視）

無効：
- 23% A + 2% B = 25%（Aが3変更、±2制限を超える）
- 17% A + 8% B = 25%（両方が±2制限を超える）
```

#### VIPティア（±4パーセントポイント）：
```
デフォルト：22%（A）+ 6%（B）+ 2%（C）= 30%合計

有効範囲：
├─ レベルA：18% - 26%
├─ レベルB：2% - 10%
└─ レベルC：0% - 6%*（*Cから2ポイントシフトすると、0%になる）

例：
- 28% A +  2% B + 0% C = 30%（最大直接焦点）
- 20% A + 10% B + 0% C = 30%（レベルBに力を与える）
- 18% A +  6% B + 6% C = 30%（深いネットワーク焦点）
- 20% A +  8% B + 2% C = 30%（バランスの取れた調整）

注：どのレベルも0%未満にはできないため、それに応じて調整してください。
```

#### Legendティア（±6パーセントポイント）：
```
デフォルト：25%（A）+ 10%（B）+ 5%（C）= 40%合計

有効範囲：
├─ レベルA：19% - 31%
├─ レベルB：4% - 16%
└─ レベルC：0% - 11%*（*6ポイントシフトすると、5% - 6 = -1% → 0%）

例：
- 31% A +  4% B + 5% C = 40%（インフルエンサー戦略）
- 26% A + 16% B +  0% C = 40%
- 19% A + 10% B + 11% C = 40%（深いネットワーク最大化）
- 25% A + 10% B + 5% C = 40%
```

### Legendティアダッシュボード

> LegendがProと比較して見るもの：

## NFT譲渡可能性

### アフィリエイトビジネスを売却

これは<mark>OROKAIの最も革新的な機能</mark>です — <mark>アフィリエイトネットワーク全体をNFT資産として売却</mark>する能力。これは暗号資産アフィリエイトプログラムでこれまでに行われたことがありません。

### 仕組み

すべてのOROKAIアカウントには、いつでもミントできる<mark>専用のアフィリエイトNFT</mark>があります。このNFTは以下を表します：

> NFTの内容：
- あなたの完全な紹介ツリー（すべてのレベルA、B、Cユーザー）
- このツリーからの将来の収益に対するスマートコントラクト権利
```
主要なメカニズム：
譲渡前：
├─ AliceがNFT #12345を所有
├─ Aliceの紹介ツリー：100レベルA + 500レベルB + 2000レベルC
├─ Aliceの収益：このネットワークから月5,000ドル
└─ Aliceのティア：Legend（彼女の1,500万ドルTVLに基づく）

AliceがNFTをミントして20万ドルでBobに売却：

譲渡後：
├─ BobがNFT #12345を所有
├─ BobはAliceのツリーからのすべての将来の収益を受け取る
├─ Bobのティア：Bob自身のTVLによって決定（Aliceのではない）
│   └─ Bobが5万ドルのTVLを持つ場合 → Premiumティア（15% Aのみ）
│   └─ Bobが2,000万ドルのTVLを持つ場合 → Legendティア（25% A、10% B、5% C）
├─ Aliceはそれらの紹介へのアクセスを失う（永久譲渡）
└─ Aliceが保持：自分のOROKAIアカウント + 新しいネットワークを構築可能
```

### なぜこれが革命的か

#### 従来のアフィリエイトプログラム：

- 収益はあなたのアカウントに永久に紐付けられる
- 売却、譲渡、または清算できない
- プロモーションを停止すると、収益が減少
- 出口戦略なし
- 資産価値なし

#### NFT譲渡を伴うOROKAI：

> アフィリエイトネットワーク = 流動資産

> オープンマーケットで売却可能（OpenSea、Blurなど）

> アフィリエイトの出口戦略（帝国を現金化）

> 相続/財産計画が可能

> 投資家がパフォーマンスの高いネットワークを購入可能

> アフィリエイトビジネスの二次市場を創出

### 評価フレームワーク

アフィリエイトNFTはいくらの価値がありますか？市場が決定します。

基本的な評価モデル：

NFT価値 ≈（月次収益 × 12～36か月）× 品質乗数

### 譲渡プロセス
```
ステップ1：NFTをミント（一度限り）
├─ ダッシュボード → アフィリエイト → [NFTをミント]に移動
├─ ネットワークガス手数料を支払う（一度限り、チェーンに応じて約10～50ドル）
├─ NFTをあなたのウォレットにミント
└─ NFT ID：一意の識別子（例：OROKAI-AFF-#12345）

ステップ2：売却リスト（オプション）
├─ OpenSea / Blur / LooksRare /任意のNFTマーケットプレイスにリスト
├─ 希望価格を設定（またはオファーを受け入れる）
├─ メタデータを含める：収益履歴、ネットワークサイズ、成長率
└─ 購入者は購入前にオンチェーンで検証可能

ステップ3：NFTを譲渡（許可不要）
├─ 購入者がNFTを購入（ピアツーピア）
├─ スマートコントラクトが自動的に：
│   ├─ 紹介ツリーの所有権を譲渡
│   ├─ 収益受取人を新しい所有者に更新
│   └─ それらの紹介へのあなたのアクセスを無効化
├─ OROKAI承認不要（完全に分散化）
└─ 即座の決済（アトミック取引）

ステップ4：譲渡後
├─ 新しい所有者は次の支払いサイクルから収益を受け取る
├─ 売り手は保持：譲渡前の未払い収益
├─ 売り手はすぐに新しいネットワークの構築を開始可能
└─ 紹介ツリーユーザーは影響を受けない（彼らには透明）
```

### リスク開示

> 評価リスク：
- 保証された買い手なし（非流動資産）
- 市場があなたの期待より低く評価する可能性
- ネットワーク収益は減少する可能性（保証されない）
- 買い手のティアが収益に影響（買い手がBasicの場合、収益が低下）

> 譲渡リスク：
- 不可逆的（譲渡後に取り消せない）
- 譲渡前の未払い収益は売り手に残る
- 新しい所有者が関係を維持しない場合、ネットワークが衰退する可能性
- 管轄区域によって異なる税務上の影響（税務顧問に相談）

> 規制：
- NFT売却はあなたの管轄区域で課税対象イベントになる可能性
- 一部の管轄区域ではNFT販売を制限する場合
- OROKAIは販売を促進しない（ピアツーピアのみ）
- OROKAIからの買い手/売り手保護なし（必要に応じてエスクローを使用）

> 技術的：
- ウォレットを保護する必要がある（NFTを失う = 収入を失う）
- スマートコントラクトリスク（監査済みだがゼロリスクではない）

## コンプライアンスと法的事項

### ピラミッドスキームではない

このセクションは、最も重要な規制上の懸念に対処します：**OROKAIのマルチレベルアフィリエイトプログラムはピラミッドスキームですか？**

**短い答え：いいえ。**理由は次のとおりです：

#### ピラミッドスキーム vs 正当なマルチレベルマーケティング

> ピラミッドスキーム（違法）の特徴：

- 主な収入が募集から（製品販売ではなく）
- 参加するために前払い投資/購入が必要
- 実際の製品やサービスがない（募集のみ）
- 持続不可能（無限の成長に依存）
- ほとんどの参加者がお金を失う
- 「すぐにお金持ちになる」ことに重点

> OROKAIアフィリエイトプログラム（合法）の特徴：

- 実際の収益からの収入（プラットフォームで取引するユーザー）
- 参加費用なし（アフィリエイトになるのは無料）
- 実際の製品/サービス（ノンカストディアルDeFiプラットフォーム）
- 持続可能（収益はプラットフォーム使用に紐付けられ、募集ではない）
- ほとんどの参加者は利益を得ることができる（価値を提供する場合）
- 価値あるネットワークの構築に重点

#### 主要な法的差別化要因

| 基準 | ピラミッドスキーム（違法） | OROKAIアフィリエイトプログラム（合法） |
|----------|----------------------------|-------------------------------------|
| **参入障壁** | 在庫を購入、会員費を支払うなど。参加者に財務リスクを作る | アフィリエイトプログラムへの参加は無料。プラットフォームの使用は無料（ノンカストディアル）。アフィリエイトになるための財務リスクゼロ |
| **収益源** | 新規募集者から古い募集者へのお金の流れ。外部収益源なし。ゼロサムゲーム（誰かが損をしなければならない） | ユーザー取引（スワップ、ステーキング、カード）からのお金の流れ。OROKAIは実際のサービス（ソフトウェア）を提供することで収益。アフィリエイトはOROKAIの収益の%を得る。プラスサム（プラットフォームの実用性を通じて価値が創造される） |
| **製品の実用性** | 製品は募集構造なしでは価値がない。募集が製品である | DeFiプラットフォームは独立した価値を持つ（集約、AI、UX）。ユーザーはアフィリエイトプログラムなしでもOROKAIを使用する。アフィリエイトは成長を加速するが、中核的な価値提案ではない。製品価値はアフィリエイト構造とは独立 |
| **経済的持続可能性** | 無限の成長が必要（指数関数的募集）。数学的に崩壊が保証されている。設計上持続不可能 | 収益は取引ボリュームに紐付けられている（成長または縮小可能）。アフィリエイト収益は実際の使用量に応じてスケール。プラットフォームが成長 → より多くの収益 → より多いアフィリエイト収益。プラットフォームが縮小 → より少ない収益 → より少ないアフィリエイト収益。持続可能（実際の需要に基づいて自己調整） |

### OROKAI固有の保護措置

#### 開示と透明性

> 規約は明確に記載：
- 収益は保証されていない
- 収入は紹介活動に依存（変動）
- OROKAIは30日前の通知で条件を変更する可能性
- 特定のリターンの約束なし
- アフィリエイトは独立（従業員ではない）

> ダッシュボードに表示：
- 正確な収益内訳（レベルA/B/C）
- 収益の出所（取引タイプ）
- 過去のパフォーマンス（将来の予測ではない）
- リアルタイムデータ（誇張された主張なし）

> マーケティングガイドラインは禁止：
- 「保証収入」の主張
- 「すぐにお金持ちになる」メッセージング
- 誤解を招く収入表示
- OROKAIを公式に装う

#### アンチピラミッド設計要素

> TVLベースのティア（募集ベースではない）：
   - ティアは展開された資本によって決定、募集数ではない
   - 純粋な募集焦点を防ぐ
   - 実際のプラットフォーム使用と整合

> マルチレベルの深さの上限：
   - 最大3レベル（A/B/C）
   - 無限深度のピラミッド構造を防ぐ
   - ほとんどの収益はレベルA（直接）から、B/Cでの収益逓減

> 実製品依存：
   - アフィリエイトは紹介者が取引した場合のみ収益
   - サインアップだけでは収益なし
   - 質の高い紹介（アクティブユーザー）を奨励

> 募集ノルマなし：
   - 最小募集要件なし
   - ステータス維持のための募集圧力なし
   - 純粋にオプション（参加せずにOROKAIを使用可能）

> 独立したプラットフォーム価値：
   - 非アフィリエイトユーザーが完全なプラットフォーム特典を得る
   - 紹介されないことによる不利益なし
   - アフィリエイトプログラムは成長ツール、中核ビジネスモデルではない

### アフィリエイトができないこと（コンプライアンス）

禁止事項：
- 「保証されたリターン」や特定の収入額を主張
- OROKAIを「投資機会」として提示（ソフトウェアです）
- リスクを誤って表現（暗号資産のボラティリティを開示する必要がある）
- 公式にOROKAIを装う（私たちの代弁者であると主張できない）
- スパムまたは一方的なアウトリーチ（スパム防止法違反）
- 制限された管轄区域をターゲット（制裁措置のコンプライアンス）
- 証券法違反（他人の仕事からの利益を約束）
- ピラミッド式募集（製品の実用性よりも募集を強調）

許可事項：
- OROKAIの仕組みを説明（教育コンテンツ）
- 自分の経験を共有（免責事項付きの推薦）
- アフィリエイト関係を開示（「私のリンクを使用すると収益が得られる」）
- 比較コンテンツを作成（他のプラットフォームと比較）
- DeFi教育を中心としたコミュニティを構築
- 実際のユーザー活動から紹介収入を得る

**執行：**

これらの規則に違反するアフィリエイトは以下に直面します：
- 警告（最初の軽微な違反）
- 停止（繰り返される違反）
- 永久禁止 + 収益の没収（重大な違反）
- OROKAIまたはユーザーに重大な害を引き起こした場合の法的措置
