# クレジットカードでのオンランプ/オフランプ

## パートナー運営サービス

### シームレスな入出金

OROKAIは、<mark>中央集権型取引所アカウントを必要とせずに、</mark>従来通貨（フィアット）と暗号資産間の移動を簡単にします。私たちは、すべてのフィアット取引、KYC/AMLコンプライアンス、カード処理を処理する<mark>ライセンス取得済み決済プロバイダー</mark>と提携しています — OROKAIは<mark>ソフトウェアインターフェースのみです。</mark>

:::warning[重要な原則]
OROKAIは<mark>フィアットマネーに触れません。</mark>パートナーがすべてのフィアット取引、銀行業務、規制コンプライアンスを処理します。私たちはあなたを彼らに接続しますが、<mark>私たちは決済サービスプロバイダー、送金業者、または銀行ではありません。</mark>
:::

### 自動プロバイダー選択

> OROKAIがユーザーの地域を検出（IP + 宣言された国）

> その地域のStripe利用可能性を確認

> Stripeが利用可能な場合：
   - Stripeウィジェットを表示（優先 - 最高のUX）
   - ユーザーがStripe経由で取引を完了
> Stripeが利用できない場合：
   - Onramperウィジェットにフォールバック
   - Onramperが最適な利用可能プロバイダーを選択
   - ユーザーがOnramperパートナー経由で取引を完了

使用されるプロバイダーに関係なく、ユーザーはシームレスな体験を得られます。

## 手数料構造

### コンポーネント1：プロバイダー手数料

#### Stripe手数料（参考、地域/決済方法により異なる）：
- 決済処理：約2～5%（カードに依存）
- 通貨換算：為替レートに含まれる
- ネットワーク手数料：ブロックチェーンガス（転嫁）
- 典型的な合計：2～5% + ネットワーク手数料

#### Onramperパートナー手数料（プロバイダー/地域により異なる）：
- 決済処理：約3～6%（プロバイダーに依存）
- 通貨換算：為替レートに含まれる
- ネットワーク手数料：ブロックチェーンガス（転嫁）
- 典型的な合計：3～6% + ネットワーク手数料

:::tip[注意]
プロバイダー手数料はStripe/Onramperパートナーによって設定され、OROKAIではありません。明確に表示しますが、これらのレートを管理していません。
:::

### コンポーネント2：OROKAIサービス手数料

> オンランプ：取引金額の1.0%

> オフランプ：取引金額の1.0%

これがカバーするもの：
- ソフトウェア統合とメンテナンス
- ユーザーインターフェースと体験
- 取引オーケストレーション
- カスタマーサポート（OROKAI側）
- ウォレット管理と通知

適用対象：受け取った暗号資産金額（オンランプ）または送信した暗号資産金額（オフランプ）

### コンポーネント3：ネットワーク手数料

ネットワーク手数料は、ブロックチェーンに取引を記録するコストであり、バリデーター/マイナーに支払われ、OROKAIや決済プロバイダーには支払われません。

仕組み：
- オンランプ：プロバイダーからあなたのウォレットへ暗号資産を配信するガス手数料
- オフランプ：あなたのウォレットからプロバイダーへ暗号資産を送信するガス手数料
- 金額は以下により変動：ネットワーク（Ethereum vs Polygon）、混雑、取引の複雑さ
- 取引確認前にリアルタイムで表示

:::warning[免責事項]
ネットワーク手数料はOROKAIまたはプロバイダーによって管理されません — 取引時のブロックチェーンネットワーク状況によって決定されます。
:::

:::tip[ヒント] 
小額取引の場合、購入/売却の割合としてネットワーク手数料を最小化するために、低コストネットワーク（Polygon、Solana）を選択してください。
:::

3. 購入した暗号資産：          970.00ドル相当のUSDC
 
4. OROKAI手数料（1%）：        -9.70ドル
（970ドルの暗号資産の1%）

5. ネットワーク手数料（ガス）： -2.50ドル
（PolygonでウォレットにUSDCを配信）

─────────────────────────────────────────────────────────────────────
あなたが受け取る：              約957.80 USDC 
─────────────────────────────────────────────────────────────────────

総手数料：42.20ドル（1,000ドルの4.22%）
 ├─ プロバイダー：30.00ドル（3.0%）
 ├─ OROKAI：9.70ドル（0.97%）
 └─ ネットワーク：2.50ドル（0.25%）
```

#### Stripe経由のオフランプ
```
ユーザーが現金化したい：1,000 USDCを銀行口座へ

2. OROKAI手数料（1%）：        -10 USDC
（1,000 USDCの1%）

3. Stripeに送信される金額：    990 USDC

4. StripeがUSDに変換：         約990.00ドル

5. Stripe出金手数料：          -15.00ドル

─────────────────────────────────────────────────────────────────────

─────────────────────────────────────────────────────────────────────

総手数料：27.50ドル（1,000ドルの2.75%）
 ├─ OROKAI：10.00ドル（1.0%）

ユーザーが操作を承認する前に、パートナー手数料とネットワークコスト（該当する場合）が表示されます。

:::tip[規制されたパートナー統合]

すべてのカードおよびフィアット操作は、ライセンス取得済み、コンプライアントなサードパーティプロバイダーによって処理されます – OROKAIはインターフェースレイヤーとしてのみ機能します。

:::

## ユーザーフロー

### オンランプ（カードで暗号資産を購入）

> **ステップ1：** ユーザーが購入を開始

ユーザーがクリック：OROKAIダッシュボードで[暗号資産を購入]

OROKAIが尋ねる：
- いくら？[USD/EUR/GBP等の金額]
- どの資産？[ETH / USDC / USDT / BTC / など]
- どのネットワーク？[Ethereum / Polygon / Solana / など]
- 決済方法？[カード / 銀行送金 / など]

> **ステップ2：** プロバイダー選択（自動）

OROKAIが検出：
- ユーザー地域：[国]
- Stripe利用可能？→ はい
- ルート先：Stripeウィジェット

（Stripeが利用できない場合 → Onramperウィジェットにフォールバック）

> **ステップ3：** 手数料開示

ユーザーは続行する前に手数料を明示的に承認する必要があります。

> **ステップ4：** Stripeウィジェットが開く（埋め込み）

StripeオンランプウィジェットがOROKAIインターフェース内に表示されます。

:::warning[重要なセキュリティ]
- カード詳細はStripeのウィジェットに直接入力されます
- OROKAIはPAN、CVV、請求情報を受け取りません
- PCI DSSコンプライアンスはStripeによって処理されます
:::
> **ステップ5：** KYC/AML（Stripeで必要な場合）

初回ユーザーまたは大額の場合、Stripeは以下を要求する場合があります：

- 本人確認（政府発行ID）
- 住所証明（公共料金請求書、銀行明細書）
- セルフィー検証（生存確認）
- 資金源（非常に大額の取引の場合）

これはStripeのフロー内で行われ、OROKAIではありません。
OROKAIはステータス更新（承認済み/保留中/拒否）を受け取ります。

> **ステップ6：** 決済処理

Stripeがカード決済を処理：

OROKAIに表示されるステータス更新：
- 決済処理中...
- 決済成功
- 暗号資産購入中...
- 暗号資産購入済み、あなたのウォレットに配信中...

ユーザーはウィンドウを閉じることができます。完了時に通知が更新されます。

> **ステップ7：** あなたのウォレットへの暗号資産配信

StripeがOROKAIが提供したウォレットアドレスにUSDCを配信
（あなたのセルフカストディウォレットアドレス）。

OROKAIがブロックチェーンで着信取引を監視：
- 取引検出：[TXハッシュ]
- ステータス：保留中（確認待ち）
- ステータス：確認済み

> **ステップ8：** 配分準備完了

ユーザーは以下が可能：
- ダッシュボードで残高を表示
- DeFi戦略に配分（セクション5.2参照）
- 後で使用するためにウォレットに保持
- さらに暗号資産を購入

### オフランプ（暗号資産をフィアットに売却）

> **ステップ1：** ユーザーが売却を開始

ユーザーがクリック：[暗号資産を売却]または[銀行に出金]

OROKAIが尋ねる：
- どの資産？[利用可能を表示：USDC、ETHなど]
- いくら？[暗号資産または$相当の金額]
- ネットワーク？[Ethereum / Polygon / など]
- 宛先？[銀行口座 / カード]

> **ステップ2：** アンステーク/引き出し（必要な場合）

暗号資産がプロトコルにステークされている場合：
- OROKAIが検出：「あなたのUSDCはAAVEにあります」
- 提案：「まずAAVEから引き出してください」
- 準備：アンステークフロー → その後オフランプ
- ユーザーが署名：引き出し取引

暗号資産がすでにウォレットで流動的な場合：
- ステップ3に直接進む

> **ステップ3：** 手数料開示

手数料は見積もりです。最終金額は変換後に確認されます。

> **ステップ4：** 暗号資産転送を準備

OROKAIがStripeのアドレスにUSDCを送信する取引を準備します。

> **ステップ5：** ユーザーが取引に署名

取引があなたのウォレット（MetaMaskなど）に表示されます：
- レビュー：金額、アドレス、ネットワーク
- 取引に署名
- ブロックチェーンにブロードキャスト

OROKAIがステータスを追跡：
- 取引保留中...
- オンチェーンで確認済み
- Stripeが変換処理中...

> **ステップ6：** Stripeが変換と転送

StripeがUSDCを受け取り：
- USDに変換（現在の市場レートで）
- 出金手数料を控除
- 銀行送金を開始（ACH/SEPAなど）

タイムライン：
- Stripeが暗号資産を受け取り：即時（オンチェーン確認）
- USD変換：1時間以内
- 銀行入金：1～3営業日（銀行に依存）

> **ステップ7：** 完了通知

OROKAIが更新を表示：
```
Stripeに暗号資産を送信
[TXハッシュリンク]

ステータス：銀行入金待ち（1～3日）
予想到着：[日付]

資金が銀行に到着したら通知を受け取ります。
```
銀行送金が完了したら：
```
出金完了！

銀行で受け取った金額： 
元の金額： 
総手数料： 

[領収書を表示] [新しい取引]
```

### フェイルオーバーの仕組み

> Stripeサポート地域のユーザー：

## 制限とコンプライアンス

### 制限

> Stripe（典型的な制限）：

- 日次：最大10,000ドル（検証レベルにより異なる）
- 週次：最大25,000ドル
- 月次：最大100,000ドル
- 取引あたり：最低50ドル、最大10,000ドル

> Onramperパートナー（異なる）：

- 選択されたパートナーと地域に依存
- 典型的：取引あたり50～5,000ドル
- 未検証ユーザーには低い制限がある場合があります

:::tip[制限]
制限はプロバイダーによって設定され、OROKAIではありません。強化されたKYC検証でより高い制限が利用可能です。
:::

### KYC/AML要件

すべてのプロバイダーが基本情報を要求：
- 氏名
- メールアドレス
- 居住国
- 決済方法（カード/銀行）

大額の場合の強化されたKYC：
- 政府発行ID（パスポート、運転免許証）
- 住所証明（公共料金請求書、銀行明細書）
- セルフィー検証（生存確認）
- 資金源（非常に大額の取引の場合）

:::warning[免責事項]
> KYCは以下によって処理：StripeまたはOnramperパートナー（OROKAIではない）

> OROKAIが受け取るのは：承認/拒否ステータスのみ

> OROKAIは決して保存しない：ID文書、SSN、機密個人データ
:::

### 禁止管轄区域

> OROKAIオン/オフランプは以下では利用できません：

- 制裁対象国（OFAC/EU制裁リストによる）
- 暗号資産取引が違法な地域
- ライセンス取得済みプロバイダーのカバレッジがない管轄区域
- 制裁リストのユーザー（プロバイダーによってチェック）

:::warning[VPN]
 地理的制限を回避するためのVPN使用は禁止されており、
アカウント停止 + 資金凍結につながる可能性があります。
:::

## 重要な原則：OROKAIのオン/オフランプ

| 原則 | 意味 |
|-----------|---------------|
| **OROKAIはフィアットに触れない** | すべてのフィアット取引はライセンス取得済みパートナー（Stripe/Onramper）によって処理されます。 |
| **透明な手数料** | 取引前にすべてのコストを表示。プロバイダー手数料 + OROKAI 1%手数料。 |
| **セルフカストディ維持** | 暗号資産はあなたのウォレットに直接配信。私たちはあなたの暗号資産を保有しません。 |
| **パートナーによるKYC** | 本人確認はStripe/Onramperによって処理され、OROKAIではありません。 |
| **自動フェイルオーバー** | StripeまたはOnramperを使用しても、シームレスな体験。 |
| **PCI DSS準拠** | カード詳細はOROKAIサーバーに触れません（プロバイダーウィジェットに入力）。 |
| **地域コンプライアンス** | 法的に許可されている場所でのみ利用可能。VPNバイパスは許可されません。 |

|------------|---------|-----------------|

| KYC問題/検証 | プロバイダーサポート | 1～3日 |
| ウォレットに資金が届かない | OROKAIサポート | 1～24時間 |
| 取引追跡 | OROKAIサポート | リアルタイム |
| 返金リクエスト | プロバイダーサポート | 5～10日 |
| 受け取った金額が不正確 | プロバイダー + OROKAI | 24～48時間 |
| 一般的な質問 | OROKAIサポート | 6～24時間 |
