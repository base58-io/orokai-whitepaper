# Intelligent Asset Management

## Informed Decision Support

### Alerts and recommendations (informational)

Upon significant changes (e.g., reward drop, increased protocol risk, cheaper DEX route), user receives notification and rebalancing/migration proposal.

The AI Agent continuously monitors your positions and market conditions, but <mark>only suggests actions when specific triggers are met.</mark> You remain in complete control — every suggestion is optional, and every action requires your signature.

### Rules and schedules

User can set rules (thresholds, intervals) for claim/re-stake or rebalancing — always as a set of transactions to sign.

### Key Principles: Intelligent Management in OROKAI

| Principle | What It Means |
|-----------|---------------|
| **Monitoring ≠ Control** | AI watches 24/7, but YOU decide all actions. |
| **Suggestions, Not Commands** | Every alert is optional. Dismiss/snooze freely. |
| **Context, Not Just Data** | AI explains WHY it's suggesting something (reason-codes). |
| **Cost-Aware** | Won't suggest actions where cost > benefit. |
| **Risk-First** | Security alerts prioritized over opportunities. |
| **Your Pace** | Set thresholds, frequency, channels to match your style. |
| **Non-Intrusive** | Default: daily digest. Critical alerts only when truly critical. |
| **Always Revocable** | Pause position monitoring, disable alert types anytime. |

:::warning[No autonomous execution]

No decisions are executed automatically; OROKAI does not manage the user's wallet — it only prepares operations and explains their consequences.

:::
