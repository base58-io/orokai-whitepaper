# Inteligentne zarządzanie aktywami

## Wsparcie świadomych decyzji

### Alerty i rekomendacje (informacyjne)

Przy istotnych zmianach (np. spadek nagród, zwiększone ryzyko protokołu, tańsza trasa DEX), użytkownik otrzymuje powiadomienie i propozycję rebalansowania/migracji.

Agent AI nieustannie monitoruje Twoje pozycje i warunki rynkowe, ale <mark>sugeruje działania tylko gdy spełnione są określone wyzwalacze.</mark> Zachowujesz pełną kontrolę — każda sugestia jest opcjonalna, a każde działanie wymaga Twojego podpisu.

### Reguły i harmonogramy

Użytkownik może ustawić reguły (progi, interwały) dla claim/re-stake lub rebalansowania — zawsze jako zestaw transakcji do podpisania.

### Kluczowe zasady: Inteligentne zarządzanie w OROKAI

| Zasada | Co to oznacza |
|-----------|---------------|
| **Monitoring ≠ Kontrola** | AI obserwuje 24/7, ale TY decydujesz o wszystkich działaniach. |
| **Sugestie, nie polecenia** | Każdy alert jest opcjonalny. Odrzucaj/wyciszaj swobodnie. |
| **Kontekst, nie tylko dane** | AI wyjaśnia DLACZEGO coś sugeruje (kody przyczyn). |
| **Świadomość kosztów** | Nie sugeruje działań gdzie koszt > korzyść. |
| **Ryzyko na pierwszym miejscu** | Alerty bezpieczeństwa priorytetyzowane nad możliwościami. |
| **Twoje tempo** | Ustaw progi, częstotliwość, kanały pasujące do Twojego stylu. |
| **Nieinwazyjne** | Domyślnie: dzienny digest. Krytyczne alerty tylko gdy naprawdę krytyczne. |
| **Zawsze odwołalne** | Wstrzymaj monitorowanie pozycji, wyłącz typy alertów w każdej chwili. |

:::warning[Brak autonomicznej egzekucji]

Żadne decyzje nie są wykonywane automatycznie; OROKAI nie zarządza portfelem użytkownika — tylko przygotowuje operacje i wyjaśnia ich konsekwencje.

:::
