# Locking / Staking / Delegation — Rules and Privileges

## Engagement Forms

### Locking options

Fixed-term locking (e.g., 30/90/180 days).

### Delegation

Delegation to selected validators.

## Possible Privileges (Examples)

### Fee discounts

Discounts on OROKAI fees (UI/routing/services).

### Operational priority

Batching priority and higher operational limits.

### Premium feature access

E.g., pro alerts, advanced reporting.

## General Rules

Program is voluntary; privileges are not "interest." Parameters, including slashing possibility (for delegation), are transparent and managed on-chain.

:::warning[Utility benefits, not yields]

Locking and delegation provide utility benefits and network participation rights, not financial returns or guaranteed yields.

:::
