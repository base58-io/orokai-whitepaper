# OROKAI Token — Utility Functions

## Core Utility Features

### Gas on OROKAI Chain

Paying for transactions and protocol services (e.g., batching, cross-chain messages).

### Staking / delegation

Participation in network security (validators/delegators), with slashing mechanisms and penalties for abuse (according to on-chain rules).

### Discounts and premium features

Fee rebates on OROKAI fees (UI/routing/analytics) and/or access to selected features after voluntary lock/stake.

### (Optional) Technical governance

Voting on protocol parameters (e.g., limits, allow-lists, fee distribution). <mark>Governance does not include financial promises or "dividends."</mark>

:::warning[Product benefits, not financial returns]

Rebates and feature access are product benefits, not interest or guaranteed income.

:::
