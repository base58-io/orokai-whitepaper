# Buyback Policy

## Token Economics Mechanisms

### Buyback & Burn (default)

Part of protocol fees may fund token buyback and burn (supply reduction), according to on-chain approved policy.

### Alternative: Buyback & Rebate

Instead of burning, tokens may fund vouchers/discounts on our fees for active users (e.g., volume-based rebates), if protocol rules provide for this.

### Treasury

Funding development, audits, grants, and security; no "dividend" type payouts. Buyback parameter changes only through governance (if enabled).

:::tip[Sustainable economics]

Buyback mechanisms align protocol economics with long-term value creation, while treasury ensures continuous development and security improvements.

:::
