# ミッションとビジョン

## ミッション

Web3以外のユーザーとパートナーのために、<mark>安全で理解しやすく、アクセスしやすい</mark>DeFiへの橋を構築すること — 資産の管理権限を奪うことなく、オンチェーンの複雑さを習得する必要なく、独立してパッシブ資産管理の機会から利益を得られるようにします。

## ビジョン

以下のようなエコシステム：

> セルフカストディが標準（ユーザーが資産を管理）

> UXが複雑さを隠蔽（ウォレットとガスの抽象化、明確な権限）

> コンプライアンス・バイ・デザイン（地理的制限、制裁措置、除外）

> 透明性とリスク管理が製品機能（制限、ホワイトリスト化されたプロトコル、警告）
