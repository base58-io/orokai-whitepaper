# ユーザーへの価値

:::tip[中核価値]

OROKAIは、100%のユーザー制御を維持しながら、DeFiの複雑さを80～90%削減します。資産のカストディを手放すことなく、プロフェッショナルグレードのDeFi管理の利点を得られます。

:::

管理されたリスクでの最小限の労力。OROKAIは、<mark>完全なユーザー制御</mark>（セルフカストディ）を<mark>維持</mark>しながら、DeFiオンボーディングと継続的なポジション管理を<mark>簡素化</mark>します。プロトコルで生成された報酬はUSDTで決済でき、コストは事前に提示されます - 各チェーンとプロトコルのニュアンスを学ぶ必要はありません。

:::warning[リターン]

リターンは変動し、保証されません。フィアット/カード決済はライセンス取得済みパートナーによって処理されます。暗号資産交換はDEXファーストです。

:::

## OROKAIバリュースタック

### あなたが得るもの

> シンプルさ
- すべてのポジション用の1つのダッシュボード（10以上のプロトコルウェブサイト vs）
- 統一された取引フロー（手動のマルチステッププロセス vs）
- すべてのアクション前の明確なコスト内訳
- 平易な言葉での説明（技術的専門用語不要）
- 5分のオンボーディング（数日の調査 vs）

> インテリジェンス
- AIガイド付き戦略選択（推測/FOMO vs）
- 継続的なモニタリング（手動チェック vs）
- プロアクティブな最適化提案（機会を逃す vs）
- リスク認識推奨（あなたのプロファイルに一致）
- 説明可能な推論（何だけでなく、なぜを理解）

> 効率性
- 時間節約：管理オーバーヘッドが約90%削減
- ワンクリックマイグレーション（6以上の手動取引 vs）
- 自動クレーム（オプション、あなたが承認）
- クロスチェーンオーケストレーション（複雑なフローを簡素化）

> セキュリティと制御
- セルフカストディ：あなたの鍵、あなたの資金（常に）
- 透明な権限：承認する内容を正確に確認
- 取り消し可能なアクセス：いつでも無効化/取り消し
- ホワイトリストプロトコル：精査、監査されたオプションのみ
- 全体を通じてノンカストディアル：私たちが準備、あなたが署名

> 透明性
- すべてのコストが署名前に表示（サプライズなし）
- 明確な手数料内訳（ガス + DEX + ブリッジ + OROKAI）
- 隠れた料金や細則なし
- リアルタイムパフォーマンス追跡

> アクセス
- マルチチェーンサポート（Ethereum、Polygon、Solana、Cosmosなど）
- プロトコル集約（ステーキング、レンディング、DEXが1か所に）
- フィアットオン/オフランプ（CEXアカウント不要）
- グローバル利用可能性（パートナー経由で180以上の国）
- モバイルとWebアクセス（どこでも管理）

### あなたが手放さないもの

> 制御
すべての取引に署名します。例外はありません。
OROKAIは資金を移動、取引を実行、またはウォレットにアクセスできません。

> 所有権
あなたの資産はあなたのウォレットまたはあなたが選択したプロトコルに留まります。
OROKAIはあなたの資金を保有、カストディ、または制御しません。

> プライバシー
あなたの鍵はあなたのデバイスを離れません。
私たちはシードフレーズ、秘密鍵、またはパスワードを見ません。

> 柔軟性
一部のポジションにはOROKAIを使用し、他のポジションには直接プロトコルを使用します。
いつでもウォレットをエクスポート（完全な可搬性）。

> 最終決定権
AI提案を無視。アラートを却下。フローをキャンセル。
あなたがすべてを決定します。

### コスト

> OROKAI手数料：
- UI/オーケストレーション手数料：特定の操作に適用（事前開示）
- オン/オフランプ：1%（+ プロバイダー手数料）
- サブスクリプションなし、月額料金なし
- 機能を使用するときのみ支払い

> パススルーコスト（OROKAI手数料ではない）：
- ブロックチェーンガス（バリデーター/マイナーに支払い）
- DEXスワップ手数料（流動性プロバイダーに支払い）
- ブリッジ手数料（ブリッジオペレーターに支払い）
- プロトコル手数料（DeFiプロトコルに支払い）
- プロバイダー手数料（オン/オフランプ：Stripe/Onramper）

> 保証なし：
- 利回りは変動（外部プロトコルによって設定）
- 市場価格は変動（暗号資産のボラティリティ）
- ガスコストは変動（ネットワーク混雑）
- OROKAIはツールを提供、投資助言ではない

## Web3外の人々のためのシンプルなDeFi参入

### 摩擦のないオンボーディング

「ゼロセットアップウォレット」（ユーザー側のウォレット。OROKAIは鍵を保存しません）とパートナーオンランプとの統合。

### ステップバイステップのガイダンス

明確なメッセージのある画面：資産に何が起こるか、ステップは何か（承認/スワップ/デポジット）、コストがいつ発生するか。

### 複数のツールの代わりに1つのウィンドウ

暗号資産購入から配分とモニタリングまで — 1つのインターフェースで、アプリケーション間をジャンプすることなく。
