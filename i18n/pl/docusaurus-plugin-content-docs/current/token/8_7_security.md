# Security and Compliance

## Security Framework

### MEV policy

Rules minimizing MEV (e.g., fair ordering/intent-based routing where possible).

### Slashing and validation

Penalties for double signing, prolonged downtime, queue manipulation; public validator telemetry.

### Audits and bug bounty

Contract/protocol audits before launch and after major updates; continuous bug bounty program.

### Geo/sanctions

Enforcement of restrictions in UI and at API level; fiat/card elements exclusively through licensed partners; no circumvention of restrictions (e.g., via VPN).

### Privacy

Minimal operational data scope; possibility of anonymization/aggregation of metrics.

:::warning[Multi-layer protection]

Security and compliance are enforced at every level – from smart contracts and network validation to UI access controls and partner integrations.

:::
