# Business Model

OROKAI monetizes the software layer and network infrastructure, <mark>not user funds.</mark>

Revenue comes primarily from fees associated with interface feature usage and partner integrations: 

> card

> staking (rewards / claim-flows)

> FIAT↔CRYPTO

> DEX swap

> cross-chain migrations

> after the OROKAI chain launch — from network fees (gas) and protocol services (e.g., batching, routing, cross-chain communication). 

Long-term, we plan premium features and token privileges (utility) — within regulatory compliance and <mark>without giving the token characteristics of a financial instrument.</mark>

:::warning[Non-custodial operation]

OROKAI operates in a non-custodial model; we do not hold funds and are not a party to fiat/card settlements — these processes are handled by licensed partners.

:::
