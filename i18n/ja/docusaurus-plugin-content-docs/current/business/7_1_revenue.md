# オンチェーン取引手数料

## 手数料構造

### 概要

:::tip[重要な原則]
ユーザーは手数料を<mark>受取人に直接</mark>支払います（流動性プロバイダー、ブリッジオペレーター、ネットワークバリデーター、OROKAI）。取引中に資金を保有することはありません。私たちの手数料は、ソフトウェアオーケストレーション、ルーティング最適化、インフラストラクチャメンテナンスに対する補償です。
:::

OROKAIは4種類のオンチェーン操作に手数料を請求します：

| 操作タイプ | 手数料コンポーネント | OROKAI収益 |
|----------------|----------------|----------------|
| **DEXスワップ** | LP手数料（プールへ） + OROKAIルーティング手数料 + ガス | [編集可能：25%] LP手数料の + [編集可能：10%] ガスマークアップ |
| **ステーキング報酬** | OROKAI自動化手数料（オプション） + ガス | [編集可能：8%] クレーム済みの + [編集可能：10%] ガスマークアップ |
| **クロスチェーンブリッジ** | ブリッジプロトコル手数料 + OROKAIオーケストレーション + ガス（両チェーン） | [編集可能：50%] ブリッジ手数料の + [編集可能：10%] ガスマークアップ |
| **マイグレーション** | 個別ステップ手数料の合計（スワップ + ブリッジ + ステーク） | 上記のステップごとの手数料 |

### DEXスワップ手数料

:::tip[ユーザーが支払うもの]
総コスト = スワップ金額 × LP手数料% + (LP手数料 × 25%) + ネットワークガス × 1.10
:::
```
例：1,000 USDC → ETHをスワップ（Uniswap V3、0.05%プール）

手数料内訳：
入力金額：1,000 USDC

LP手数料（0.05%）：0.50ドル
├─ 支払先：Uniswap流動性プロバイダー
└─ ユーザー支払い：0.50ドル

OROKAIルーティング手数料（LPの25%）：0.125ドル
├─ 支払先：OROKAI（ソフトウェアオーケストレーション）
└─ ユーザー支払い：0.125ドル

ネットワークガス：2.50ドル（0.1 Gwei、Ethereum）
OROKAIガスマークアップ（10%）：0.25ドル
├─ 支払先：バリデーター（2.50ドル） + OROKAI（0.25ドル）
└─ ユーザー支払い：2.75ドル合計ガス

═══════════════════════════════════════════════
総コスト：0.625ドル手数料 + 2.75ドルガス = 3.375ドル
ユーザー受取：約996.625 USDC相当のETH
実効レート：0.3375%
```

> #### プール手数料の影響
>
> 異なる流動性プールには異なる手数料があります。OROKAIは

**コスト vs 流動性**のバランスを取って最適なプールにルーティングします：

| プールタイプ | LP手数料 | OROKAI手数料（25%） | 総手数料 | 使用時 |
|-----------|--------|------------------|------------|-----------|
| 0.01%プール | 0.10ドル | 0.025ドル | 0.125ドル | ステーブルペア（USDC/USDT） |
| 0.05%プール | 0.50ドル | 0.125ドル | 0.625ドル | 一般的なペア（ETH/USDC） |
| 0.3%プール | 3.00ドル | 0.75ドル | 3.75ドル | 標準ペア |
| 1%プール | 10.00ドル | 2.50ドル | 12.50ドル | エキゾチック/ボラティルペア |

**ガスコストの変動性：**

スワップコストはEthereumネットワークの混雑によって劇的に変化します：

| ネットワーク状態 | ガス価格 | ネットワークガス | OROKAIマークアップ | 総ガス | 総スワップコスト |
|---------------|-----------|-------------|---------------|-----------|-----------------|
| 非常に低い（現在） | 0.1 Gwei | 0.45ドル | 0.045ドル | 0.50ドル | 1.125ドル（0.11%） |
| 低い | 5 Gwei | 22.50ドル | 2.25ドル | 24.75ドル | 25.375ドル（2.54%） |
| 通常 | 15 Gwei | 67.50ドル | 6.75ドル | 74.25ドル | 74.875ドル（7.49%） |
| 高い | 50 Gwei | 225.00ドル | 22.50ドル | 247.50ドル | 248.125ドル（24.81%） |

### ステーキング報酬手数料

:::tip[ユーザーが支払うもの]
クレーム手数料 = クレーム金額 × 8% + ガス × 1.10（クレーム取引） + ガス × 1.10（手数料取引）
:::
```
例：Lido stETH自動クレーム（1 stETH報酬）

手数料内訳：
クレーム可能報酬：1 stETH（ETH 3,000ドルで約3,000ドル）

プロトコル手数料（Lido）：発生前に既に控除（約10%）
├─ これは1 stETHには表示されません
└─ 総報酬は約1.11 stETHでした。Lidoが約0.11 stETHを取得

OROKAI自動化手数料（8%）：0.08 stETH（約240ドル）
├─ 支払先：OROKAI（サービス料）
├─ 課金：クレーム後の個別取引として
└─ ユーザー承認：クレーム有効化時

ガス（クレーム取引）：1.50ドルネットワーク + 0.15ドルマークアップ = 1.65ドル
ガス（手数料取引）：1.25ドルネットワーク + 0.12ドルマークアップ = 1.37ドル

═══════════════════════════════════════════════
総コスト：0.08 stETH + 3.02ドルガス
ユーザー受取：0.92 stETH（約2,760ドル）
プロトコルが既に取得：約0.11 stETH
グロスに対するネット：0.92 / 1.11 = 82.8%（プロトコル + OROKAI手数料）
```

### クロスチェーンブリッジ手数料

:::tip[ユーザーが支払うもの]
総ブリッジコスト = ブリッジプロトコル手数料 + (プロトコル手数料 × 50%) OROKAI + スワップ手数料（ソース） + スワップ手数料（宛先） + ガス（ソースチェーン） × 1.10 + ガス（宛先チェーン） × 1.10
:::

ブリッジは**チェーン間の複数のステップ**を含むため複雑です。
```
例：1 ETHをブリッジ（Ethereum → Polygon）

ステップ1：ETH → USDCスワップ（Ethereum）
ステップ2：USDCブリッジ（Ethereum → Polygon）CCTP経由
ステップ3：USDC → ETHスワップ（Polygon）

統合手数料サマリー：

開始金額：1 ETH（約3,000ドル）

すべてのスワップ手数料：
├─ ステップ1 LP（0.05%）：1.50ドル
├─ ステップ1 OROKAI（25%）：0.375ドル
├─ ステップ3 LP（0.05%）：1.497ドル
└─ ステップ3 OROKAI（25%）：0.374ドル
└─ スワップ小計：3.746ドル

ブリッジ手数料：
├─ CCTPプロトコル（0.001%）：0.03ドル
└─ OROKAIオーケストレーション（50%）：0.015ドル
└─ ブリッジ小計：0.045ドル

すべてのガス（Ethereum + Polygon）：
├─ Ethereumネットワーク：1.00ドル（スワップ + ブリッジ開始）
├─ Ethereum OROKAIマークアップ：0.10ドル
├─ Polygonネットワーク：0.10ドル（受信 + スワップ）
└─ Polygon OROKAIマークアップ：0.11ドル
└─ ガス小計：1.31ドル

═══════════════════════════════════════════════
総コスト：3.79ドル手数料 + 1.31ドルガス = 5.10ドル
最終受取：0.9983 ETH（約2,994.90ドル）
実効コスト：0.17%
```

**ブリッジにおけるガスシナリオの影響：**

ブリッジは**2つのチェーン**での取引を含むため、ガスコストが複合されます：

| Ethereumガス | Ethガスコスト | Polygonガス | 総ガス | 総ブリッジコスト |
|--------------|--------------|-------------|-----------|-------------------|
| 0.1 Gwei（現在） | 1.00ドル | 0.10ドル | 1.31ドル | 5.10ドル（0.17%） |
| 5 Gwei | 100.00ドル | 0.10ドル | 110.11ドル | 113.90ドル（3.80%） |
| 30 Gwei | 600.00ドル | 0.10ドル | 660.11ドル | 663.90ドル（22.13%） |

**なぜUSDC経由でブリッジ？**
- ステーブルコインのブリッジ手数料が低い（0.001% vs ラップ資産の0.02%以上）
- CCTPはネイティブUSDC（ラップ中間なし = より安全）
- 両チェーンでUSDCペアのより良い流動性

**ブリッジが意味を持つ時：**

以下の場合にブリッジ：
- 宛先チェーンがX%より良いAPYを提供（ブリッジコストをカバー）
- ガスが低い（Ethereumで5 Gwei）
- ポジションサイズが十分に大きい（ブリッジコストがポジションの1%）
- 長期ポジション（すぐに戻らない）

OROKAIは損益分岐点を計算し、最適なタイミングを提案します。

### マイグレーション手数料（マルチステップ操作）

:::tip[ユーザーが支払うもの]
マイグレーションコスト = アンステークガス + スワップ手数料 + ブリッジ手数料 + スワップ手数料 + ステークガス（上記のステップごとのOROKAI手数料を含むすべて）
:::

マイグレーションは**最も複雑な**操作で、2つのチェーンにわたって最大6つの取引を含みます。
```
例：5 ETHをマイグレーション（プロトコルA Ethereum → プロトコルB Polygon）

完全なフロー：
ステップ1：プロトコルAからアンステーク（Ethereum）
ステップ2：ETH → USDCスワップ（Ethereum）
ステップ3：USDCブリッジ（Ethereum → Polygon）
ステップ4：USDC → ETHスワップ（Polygon）
ステップ5：プロトコルBを承認（Polygon）
ステップ6：プロトコルBにステーク（Polygon）

統合コストサマリー：
開始ポジション：5 ETHステーク済み（約15,000ドル）

すべての手数料：
├─ スワップ手数料（0.05%プール）：14.995ドルLP + 3.749ドルOROKAI
├─ ブリッジ手数料：0.15ドルプロトコル + 0.075ドルOROKAI
└─ 手数料小計：18.97ドル（0.126%）

すべてのガス（6取引）：
├─ Ethereum（3取引）：1.44ドルネットワーク + 0.13ドルOROKAI
├─ Polygon（3取引）：0.54ドルネットワーク + 0.20ドルOROKAI
└─ ガス小計：2.31ドル

═══════════════════════════════════════════════
総マイグレーションコスト：21.28ドル（0.142%）
最終ポジション：Polygonに4.9965 ETHステーク済み
時間：20～40分
```

**マイグレーションにおけるガスの影響（6取引）：**

| Ethereumガス | 総ガスコスト | 総マイグレーションコスト | 15,000ドルポジションの% |
|--------------|----------------|----------------------|-------------------|
| 0.1 Gwei（現在） | 2.31ドル | 21.28ドル | 0.14% |
| 5 Gwei | 159.54ドル | 178.51ドル | 1.19% |
| 30 Gwei | 951.54ドル | 970.51ドル | 6.47% |

**マイグレーション決定フレームワーク：**

OROKAIはユーザーがマイグレーションが価値があるかどうかを判断するのを支援します。
:::tip[決定]
マイグレーションが意味を持つのは：

年間利益 > マイグレーションコスト / レビューまでの月数
:::
```
例：
- 現在のAPY：15,000ドルで4% = 年間600ドル
- 目標APY：15,000ドルで6% = 年間900ドル
- 利益：年間300ドル = 月25ドル
- マイグレーションコスト：21.28ドル（低ガス時）
- 損益分岐点：1か月未満

1か月以上滞在予定であれば、マイグレーションは収益的。

OROKAIはこれを自動的に計算し、表示します：
「マイグレーションはX日で元が取れます」
```

### ガスマークアップの説明

OROKAIはすべてのガス見積もりに**[編集可能：10%]マークアップ**を追加します。理由と仕組みは以下の通りです：

#### ガスマークアップの目的：
> インフラストラクチャコスト
   - RPCノードアクセス（マルチプロバイダー冗長性）
   - リアルタイムガス価格モニタリング
   - 取引シミュレーションと見積もり
   - 失敗した取引の検出と再試行ロジック

> ユーザー保護
   - 価格変動のバッファを含む見積もり
   - 失敗した取引を削減（ユーザーはいずれにせよガスを支払う）
   - 飛行前チェックがコストのかかるエラーを防止

> サービス手数料
   - オーケストレーション、バッチング、最適化の補償

#### 仕組み：
> ステップ1：OROKAIが実際のネットワークガス必要量を見積もり
- 複数のRPCプロバイダーにクエリ
- 取引をシミュレート
- 現在のガス価格を取得（例：0.1 Gwei）

> ステップ2：総コストを計算
- 必要なガス単位：150,000（スワップの場合）
- ネットワークコスト：150k × 0.1 Gwei × ETH価格 = 0.45ドル
- ユーザーが見る：0.45ドル × 1.10 = 0.50ドル（10%マークアップ含む）

> ステップ3：ユーザーが署名時に合計を支払い
- 0.45ドルがネットワークバリデーターへ
- 0.05ドルがOROKAIへ（サービス手数料）

#### ユーザー透明性：
UIで、ユーザーは**ガス詳細を展開**できます：

#### ガス最適化機能：
OROKAIはガスをマークアップするだけでなく、ユーザーの節約を支援します：

- **低ガスアラート：** ガスが平均を下回ったときに通知（50～90%節約）
- **バッチ提案：** 総取引数を削減するために操作を組み合わせ
- **チェーン推奨：** Ethereumガスが高いときにL2を提案
- **タイミング最適化：** AIが操作のための最適な時間ウィンドウを提案


## 手数料サマリーテーブル

| 操作 | OROKAI手数料 | 典型的なコスト範囲 | コストが低い時 | コストが高い時 |
|-----------|-------------|-------------------|------------------|-------------------|
| **スワップ** | LPの25% + ガスの10% | 0.50～250ドル | 低ガス + 0.05%プール | 高ガス + 1%プール |
| **ステーキング（自動）** | クレーム済みの8% + ガスの10% | 6～300ドル | 小額クレーム、低ガス | 大額クレーム、高ガス |
| **ブリッジ** | ブリッジ手数料の50% + スワップ手数料 + ガスの10% | 5～700ドル | 低ガス、CCTP経由USDC | 高ガス、ラップ資産 |
| **マイグレーション** | ステップごとの手数料（合計） | 20～1,000ドル以上 | 低ガス、L2宛先 | 高ガス、複数ブリッジ |

:::tip[透明な手数料モデル]

すべての手数料はユーザー承認前に開示されます – OROKAIはソフトウェアとインフラストラクチャサービスを収益化し、カストディや資産管理ではありません。

:::
