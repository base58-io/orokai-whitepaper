- アフィリエイトネットワークを資産として売却

- カード、スワップ、ステーキング、ブリッジ、オン/オフランプ

# 手数料ポリシーと割引

## 中核価格設定哲学

OROKAIの手数料構造は、ユーザーのアクティビティとトークン保有に基づいて**透明、競争力があり、調整可能**になるように設計されています。このセクションでは、価格設定哲学、割引メカニズム、将来のトークンユーティリティ機能について概説します。

### 一般原則

> 透明性第一

- すべての手数料がユーザーが取引に署名する前に表示
- 内訳が利用可能（ネットワーク、プロトコル、OROKAI）
- 隠れた料金なし、予想外の控除なし

> 価値ベースの価格設定

- 手数料は提供される価値を反映（オーケストレーション、AI、UX）
- より高い複雑さ = より高い手数料（マイグレーション vs シンプルなスワップ）
- 代替案と比較可能（最低ではないが、最高の価値）

> 調整可能で公平

- OROKAIは30日前の通知で手数料を調整する可能性
- 市場競争力（競合他社の価格を監視）

### 手数料調整ポリシー

#### OROKAIが手数料を変更する可能性がある時期と方法（手数料レビューのトリガー）
> 四半期レビューサイクル：
- 競合他社の価格分析
- インフラストラクチャコストの変更
- ユーザーフィードバックと使用パターン
- 市場状況（弱気 vs 強気）
- 規制要件

> アドホックレビュー（必要な場合）：
- 主要なパートナー手数料変更（例：V Plus Payが価格を調整）
- プロトコルコスト変更（例：DEXがLP手数料を増加）
- 重大なインフラストラクチャコストスパイク
- 緊急調整（まれ）

#### プロセス
```
1. 内部分析（OROKAIチーム）
   ├─ データレビュー（コスト、収益、使用）
   ├─ 競争ベンチマーク
   └─ 影響モデリング（ユーザーへの影響）

2. 提案（調整が必要な場合）
   ├─ 新しい手数料スケジュールの草案
   ├─ 根拠の文書化
   └─ ユーザー影響の見積もり

3. 通知（最低30日前の通知）
   ├─ アプリ内アナウンス
   ├─ 説明付きブログ投稿
   └─ 質問のためのFAQ

4. コミュニティインプット（オプション、ガバナンスがアクティブな場合）
   ├─ ディスカッション期間（14日）
   ├─ フィードバック収集
   └─ 必要に応じて調整

5. 実装
   ├─ 30日以上の通知後
   ├─ 明確な日付を伝達
   └─ 古い手数料は短期間既得権化（7日間の重複）
```

```

├─ ステーク期間（長いロック = より多い投票権）
└─ プラットフォーム活動（アクティブユーザーはボーナス投票を得る）

提案プロセス：
1. コミュニティメンバーが提案を提出
2. 正式な提案（オンチェーン、Xトークン閾値が必要）
3. 投票期間（7～14日）
4. 実行（過半数/特別多数によって承認された場合）
5. 実装（手数料増加の場合は30日前の通知）

制限：
├─ すべての手数料を排除する投票はできない（持続不可能）
├─ 50%を超える割引に投票できない（経済を壊す）
└─ コアチームは拒否権を保持（安全のため、一時的）
```

### 要約：手数料哲学

OROKAIの手数料へのアプローチ：

> 透明性
- ユーザーは常に何を支払っているか、なぜかを知っている

> 競争力
- 代替案と比較可能な手数料（最低ではないが、公平）

> 価値ベース
- より高い価値の機能にはより高い手数料

> ロイヤルティ報酬（将来）
- トークン保有者と大量ユーザーは割引を得る

> 持続可能性
- 手数料はコスト + 開発 + 成長をカバーする必要がある

> コミュニティ主導（将来）
- ユーザーはガバナンスを通じて手数料ポリシーに影響を与えることができる

> 調整可能だが安定
- 手数料を変更できるが、頻繁または劇的ではない

**目標：** 忠実なユーザーとトークン保有者に報酬を与えながら、**公平、透明、持続可能**な手数料構造を作成する。
