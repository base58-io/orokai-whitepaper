# Unikalna propozycja wartości (USP) i dla kogo jest produkt

## USP OROKAI

### Non-custodial by design
OROKAI nie posiada środków użytkowników, działa jak warstwa orkiestracji transakcji podpisywanych przez użytkownika.

### Jedno miejsce → wiele łańcuchów i protokołów
Agregacja DeFi z automatyzacją alokacji, claimów i migracji.

### Agent AI
Rekomendacje <mark>o charakterze informacyjnym</mark> dostosowane do profilu użytkownika (preferencje, doświadczenie, tolerancja ryzyka). Nie stanowi porady inwestycyjnej.

### „Zero-friction” UX
Maksymalne uproszczenie procesu wejścia i zarządzania pozycjami (w tym wsparcie on-/off-ramp przez licencjonowanych partnerów).

### Przejrzystość
Nagrody generowane przez protokoły mogą być rozliczane w USDT; ich <mark>poziom jest zmienny i niegwarantowany.</mark>


## Dla kogo

Osoby spoza web3 (prostota), użytkownicy krypto (automatyzacja/optimizacja), partnerzy B2B/B2B2C (API/white-label — model non-custodial)
