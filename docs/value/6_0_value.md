# Value for Users

Minimal effort with controlled risk. OROKAI <mark>simplifies</mark> DeFi onboarding and ongoing position management while <mark>maintaining full user control</mark> (self-custody). Protocol-generated rewards can be settled in USDT, and costs are presented upfront - without the need to learn the nuances of each chain and protocol.

:::warning[Returns]

Returns are variable and not guaranteed; fiat/card settlements are handled by licensed partners; crypto exchanges are DEX-first.

:::

## Simple DeFi Entry for People Outside Web3

### Frictionless onboarding

"Zero-setup wallet" (wallet on the user's side; OROKAI does not store keys) and integration with partner on-ramp.

### Step-by-step guidance

Screens with clear messages: what happens with assets, what are the steps (approve/swap/deposit), when costs occur.

### One window instead of multiple tools

From crypto purchase to allocation and monitoring — in one interface, without jumping between applications.

:::tip[Accessibility without compromise]

OROKAI makes DeFi accessible to newcomers while preserving the core principles of decentralization and self-custody.

:::
