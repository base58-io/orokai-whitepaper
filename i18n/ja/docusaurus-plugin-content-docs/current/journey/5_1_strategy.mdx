# 戦略選択と最初の配分

## 6ステッププロセス

すべてのユーザーの最初の配分は、プロファイルと好みに基づいたガイド付き決定木に従います。

```
開始：ウォレットに資金がある
│
├─ ステップ1：プロファイルをレビュー
│  │
│  ├─ プロファイル完成？
│  │  ├─ はい → ステップ2へ続く
│  │  └─ いいえ → クイックセットアップ（5～10分）
│  │           ├─ 目標（パッシブインカム/成長/保全）
│  │           ├─ リスク許容度（保守的/バランス/積極的）
│  │           ├─ 時間軸（短期/中期/長期）
│  │           └─ 好み（チェーン、資産、流動性ニーズ）
│  │
│  └─ プロファイルレビュー完了 → 進む
│
├─ ステップ2：AIがマッチしたオプションを表示
```

### ステップ2 – AIがマッチしたオプションを表示
```
├─ ステップ2：AIがマッチしたオプションを表示（通常3つ）
│  │
│  ├─ オプションA：推奨（あなたのプロファイルに最適）
│  │  ├─ プロトコル詳細（名前、タイプ、APY範囲）
│  │  ├─ リスクスコア（あなたの許容度に一致）
│  │  ├─ コスト見積もり（ガス + 手数料）
│  │  ├─ 必要なステップ（例：「3ステップ：承認 → スワップ → ステーク」）
│  │  └─ 理由コード（「なぜこれ？」）
│  │
│  ├─ オプションB：代替案（異なるトレードオフ）
│  │  └─ [オプションAと同じ構造]
│  │
│  └─ オプションC：代替案（異なるアプローチ）
│     └─ [オプションAと同じ構造]
│
├─ ステップ3：ユーザー決定ポイント
```

### ステップ3 – ユーザー決定ポイント
```
├─ ステップ3：ユーザー決定ポイント
│  │
│  ├─ 「オプションAが欲しい」 → ステップ4へ進む
│  │
│  ├─ 「配分をカスタマイズしたい」
│  │  ├─ オプション間の割合を調整
│  │  ├─ 複数の戦略を混合
│  │  └─ カスタム制限を設定 → ステップ4へ進む
│  │
│  ├─ 「もっとオプションを見せて」
│  │  ├─ AIが次の3つの代替案を表示
│  │  └─ ステップ2に戻る
│  │
│  ├─ 「まずプロファイルを調整する必要がある」
│  │  ├─ 目標/リスク/好みを変更
│  │  ├─ AIが推奨を再計算
│  │  └─ ステップ2に戻る
│  │
│  └─ 「自分で調査したい」
│     ├─ プロトコルリストに移動（ホワイトリストのみ）
│     └─ 手動選択 → ステップ4へ進む
│
├─ ステップ4：取引フローをレビュー
```

### ステップ4 – 取引フローをレビュー
```
├─ ステップ4：取引フローをレビュー
│  │
│  │  OROKAIが完全なフローを準備：
│  │
│  ├─ フロープレビュー：
│  │  ├─ ステップ1：[アクション]（例：「Lidoコントラクトを承認」）
│  │  │   ├─ 内容：「LidoにX額へのアクセスを許可」
│  │  │   ├─ コスト：推定ガス
│  │  │   └─ セキュリティ：承認範囲（制限付き vs 無制限）
│  │  │
│  │  ├─ ステップ2：[アクション]（例：「Uniswap経由でUSDC → ETHをスワップ」）
│  │  │   ├─ 内容：「ステーキング用に資産を交換」
│  │  │   ├─ コスト：ガス + LP手数料 + スリッページ見積もり
│  │  │   └─ 期待出力：受け取る金額
│  │  │
│  │  └─ ステップ3：[アクション]（例：「LidoでETHをステーク」）
│  │      ├─ 内容：「ステーキングプロトコルにデポジット」
│  │      ├─ コスト：ガス見積もり
│  │      └─ 期待ポジション：トークン量 + APY範囲
│  │
│  ├─ 合計サマリー：
│  │  ├─ 総ガスコスト：[見積もり]
│  │  ├─ 総手数料：[DEX + ブリッジ + OROKAI]
│  │  ├─ 総ステップ：[数]
│  │  ├─ 推定時間：[分]
│  │  └─ 期待ポジション価値：[あなたの資産での金額]
│  │
│  └─ ユーザーは何かに署名する前にすべてを確認
│
├─ ステップ5：コストとリスクの確認
```
### ステップ5 – コストとリスクの確認
```
├─ ステップ5：コストとリスクの確認
│  │
│  ├─ レビュー画面に表示：
│  │  ├─ リスク警告：
│  │  │   ├─ プロトコルリスクレベル（低/中/高）
│  │  │   ├─ 流動性制約（ある場合）
│  │  │   ├─ ロックアップ期間（ある場合）
│  │  │   └─ 変動APY免責事項
│  │  │
│  │  ├─ コスト内訳：
│  │  │   ├─ ネットワークガス手数料
│  │  │   ├─ DEX/ブリッジ手数料（該当する場合）
│  │  │   ├─ プロトコル手数料（該当する場合）
│  │  │   ├─ OROKAI UI手数料
│  │  │   └─ 総最大コスト（最悪の場合）
│  │  │
│  │  └─ セキュリティチェックリスト：
│  │      ├─ ✓ プロトコルがホワイトリストにある（監査済み）
│  │      ├─ ✓ コントラクトアドレス検証済み
│  │      ├─ ✓ ネットワーク正しい（Ethereum/Polygonなど）
│  │      ├─ ✓ 承認範囲：[正確な金額または制限付き]
│  │      └─ ✓ あなたのウォレットに十分なガスがある
│  │
│  ├─ ユーザー決定：
│  │  ├─ 「良さそう、進む」 → ステップ6
│  │  ├─ 「設定を調整」（スリッページ、ガス優先度） → 再計算 → ステップ5
│  │  ├─ 「高すぎる、低ガスを待つ」 → アラート設定 → 終了
│  │  └─ 「キャンセル」 → ステップ2に戻る
│  │
│  └─ 確認必要：[チェックボックス]「リスクとコストを理解しました」
│
├─ ステップ6：署名フェーズ（重要 - あなたが制御）
```
### ステップ6 – 署名フェーズ
```
├─ ステップ6：署名フェーズ（重要 - あなたが制御）
│  │
│  │  OROKAIはあなたに代わって署名しません
│  │
│  ├─ フローの各ステップについて：
│  │  │
│  │  ├─ 取引があなたのウォレットに表示（MetaMask/WalletConnectなど）
│  │  │  ├─ 取引詳細をレビュー
│  │  │  ├─ 検証：受信者アドレス、金額、ネットワーク
│  │  │  ├─ ガス手数料を確認（最後にもう一度）
│  │  │  └─ 署名または拒否（あなたの選択）
│  │  │
│  │  ├─ 署名された場合：
│  │  │  ├─ 取引がブロックチェーンにブロードキャスト
│  │  │  ├─ OROKAIがステータスを追跡（保留中 → 確認済み）
│  │  │  ├─ プログレスバー更新
│  │  │  └─ 確認されたら次のステップへ移動
│  │  │
│  │  └─ 拒否された場合：
│  │     ├─ フロー一時停止
│  │     ├─ 後で再開するオプション
│  │     └─ フロー全体をキャンセルするオプション
│  │
│  └─ マルチステップ処理：
│     ├─ ステップ1署名 → 確認待ち → ステップ2を提示
│     ├─ ステップ2署名 → 確認待ち → ステップ3を提示
│     └─ すべてのステップ完了 → ステップ7へ進む
│
├─ ステップ7：確認とポジション追跡
```

```
│  │
│  ├─ 成功画面：
│  │  ├─ すべての取引確認済み
│  │  ├─ あなたの新しいポジション：
│  │  │   ├─ プロトコル：[名前]
│  │  │   ├─ ステーク量：[Xトークン]
│  │  │   ├─ 現在価値：[$相当]
│  │  │   ├─ 期待APY範囲：[変動]
│  │  │   └─ 次回報酬発生：[時間枠]
│  │  │
│  │  ├─ 実際のコスト：
│  │  │   ├─ 総ガス支出：[実際 vs 見積もり]
│  │  │   ├─ 支払った手数料：[内訳]
│  │  │   └─ ブロックエクスプローラーへのリンク
│  │  │
│  │  └─ 今できること：
│  │      ├─ ダッシュボードでポジションを表示
│  │      ├─ 報酬通知を設定
│  │      ├─ 自動クレームを有効化（オプション）
│  │      └─ 承認をレビュー/取り消し
│  │
│  └─ ポジションが統一ダッシュボードに表示されるようになりました
│
└─ 継続中：継続的なモニタリング開始（セクション5.4参照）
   ├─ AIがAPY変更を追跡
   ├─ リバランス機会を監視
   ├─ クレームウィンドウのアラート
   └─ 有益な場合にマイグレーションを提案
```

### ユーザーが結果を制御する主要な決定ポイント

| 決定ポイント | ユーザーオプション | OROKAIの役割 |
|----------------|-------------|-------------|
| **プロファイル設定** | 目標、リスク、ホライゾン、好み | デフォルトを提案、ユーザーが決定 |
| **戦略選択** | 推奨または代替案を選択 | オプションを表示、ユーザーが選択 |
| **カスタマイズ** | 配分を調整、戦略を混合 | フローを準備、ユーザーが承認 |
| **コスト受け入れ** | 進むかより良い条件を待つ | コストを表示、ユーザーが決定 |
| **各署名** | すべての取引に署名または拒否 | 取引を準備、ユーザーが署名 |
| **承認範囲** | 制限付き vs 無制限権限 | 制限付きを推奨、ユーザーが選択 |
| **配分後** | 監視、クレーム、マイグレーション、終了 | アクションを提案、ユーザーが実行 |

:::tip[中核原則]
すべての決定ポイントで、あなたが最終決定権を持ちます。
OROKAIは情報提供、準備、ガイドを行います — あなたが決定し実行します。
:::


:::warning[「ベストエグゼキューション」なし]
OROKAIは最良価格を保証しません。署名前にコストとスリッページを表示します。
:::
