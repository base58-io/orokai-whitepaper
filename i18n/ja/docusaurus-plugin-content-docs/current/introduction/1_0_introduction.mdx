# OROKAIの紹介

## **OROKAIの誕生秘話**

*シンガポール、2023年。34歳の起業家マリアは、メモ帳を片手にノートパソコンの前に座っている。彼女は今、ETHをステーキングすることで年利4〜6%を獲得できるという記事を読んだばかりだ。銀行の1%をはるかに上回る利回りだ。彼女には5万ドルの貯金があり、試してみる準備ができている。*

*彼女はLido.fiを開く。「ウォレットを接続」というボタンが表示される。マリアは暗号資産ウォレットを持っていない。彼女はGoogleで「イーサリアムウォレットの作り方」を検索する。Metamaskが見つかる。インストール中、12個のランダムな単語が表示される：「シードフレーズ – これを書き留めて、決して誰にも共有しないでください。紛失すると、すべてを失います。」*

*マリアは恐怖を感じる。これは、リセットできる銀行のパスワードとは違う。これは...取り返しがつかない。彼女はタブを閉じる。*

*3ヶ月後、インフレがさらに彼女の貯金の0.5%を奪う。マリアはまだDeFiを利用していない。*

---

**これはマリアの問題ではない。これはDeFiの問題だ。**

インターネットにアクセスできる人々の95%は、DeFiプロトコルを決して使用しない – 使いたくないからではなく、**参入障壁が高すぎる**からだ。ウォレット。秘密鍵。ガス代。プロトコルの選択。外国のトークンでの取引。

**OROKAIはこの問題を解決する – ユーザーから管理権限を奪うことなく。**

## OROKAIとは

### ソフトウェアレイヤー

**OROKAI**は、従来型金融（TradFi）と分散型金融（DeFi）の世界を接続する<mark>ノンカストディアル</mark>ミドルウェアソフトウェアレイヤーです。私たちの目標は、ユーザーが独立して（<mark>セルフカストディ</mark>）<mark>自身の</mark>オンチェーン取引を準備し署名できるようにすることで、選択した外部DeFiプロトコルに資産を投入し、それらのプロトコルの規則に従ってUSDTで報酬を受け取れるようにすることです。

### OROKAIの役割

**OROKAI**は、ユーザーの資金を<mark>保有せず</mark>、秘密鍵へのアクセスを<mark>持たず</mark>、ユーザーに代わって取引を<mark>実行せず</mark>、資産を<mark>管理せず</mark>、保管サービスや投資助言を<mark>提供しません</mark>。ユーザーは資金の完全な管理権限を保持し、**すべての操作はユーザーによって承認され、ユーザーの指示に従ってスマートコントラクトによって実行されます。**


:::warning[免責事項]

**OROKAI**は、ユーザーの資金を保有せず、秘密鍵へのアクセスを持たず、ユーザーに代わって取引を実行せず、資産を管理せず、保管サービスや投資助言を提供しません。

:::

## 基本原則

### 役割の分離
OROKAIのインターフェース ≠ プロトコル。OROKAIは、いかなる外部DeFiプロトコルも管理、運営、または操作せず、ユーザーとこれらのプロトコル間の決済当事者ではありません。

### 助言サービスの不提供
AIエージェントモジュールの出力を含む情報は、情報提供のみを目的としており、投資、法律、または税務に関する助言を構成するものではありません。

### リスク
オンチェーン取引は不可逆的です。暗号資産市場は変動性が高く、いわゆる「ステーブルコイン」はペッグを維持しない可能性があります。トークン/コントラクト、ブリッジ、スマートコントラクトの誤認識のリスクがあります。

### 利用可能性/制裁措置
特定の管轄区域では、インターフェースの使用が禁止される場合があります。制限の回避（VPNなど）は禁止されています。制裁リストに掲載されている事業体による使用は認められません。
