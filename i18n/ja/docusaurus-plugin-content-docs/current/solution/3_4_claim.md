# USDTでの報酬支払いと透明なコスト

## 柔軟な決済オプション

### USDT決済（オプション）

選択されたプロトコルによって生成された報酬は、クレームでき、ユーザーが設定すれば、ホワイトリストのDEXを通じてUSDTに交換できます。

### コストの可視性

取引に署名する前に、UIは推定コスト（ガス、プロトコル/ブリッジ/DEX手数料、スリッページ）を表示します。

### リターン保証なし

報酬額と為替レートは<mark>変動し</mark>、外部プロトコル/市場に依存します。OROKAIはそれらを保証しません。

### レポート

「結果」ビューは指標を標準化し、チェーン、プロトコル、戦略、決済通貨（USDTを含む）でフィルタリングできます。

:::warning[変動するリターン]

すべてのリターンは、市場状況およびプロトコルのパラメーターに依存します。USDTまたはその他のステーブルコインへの変換は、DEXにおける市場レートで行われ、レートは変動する可能性があります。

:::
