# ユーザープロファイル（目標、好み、リスク許容度）

## プロファイルの範囲（ユーザー宣言）

### 目標
資本保全 / パッシブインカム / LST/LRTエクスポージャー / クロスチェーン分散。

### 時間軸と流動性
ロックアップなし / 許容可能なロックアップ / 柔軟な出口。

### リスクの好み
保守的 / バランス / 積極的（制限付き）。

### 経験レベル
Web3外 / 初心者 / 上級者（説明の深さに影響）。

### 運用上の好み
決済通貨（例：USDT）、チェーン/プロトコルのバスケット、最大ステップ数、手数料の制約。

## プロファイル構築の仕組み：ステップバイステップ

AI Agentの推奨は、受け取るプロファイルデータと同じくらい良いものです。以下は、OROKAIが**シンプルに保ちながら**包括的なユーザープロファイルを構築する方法です：

### ステップ1：目標

DeFiで何を達成したいですか？
```
例：
[   ] 資本保全
     → 安定したプロトコルに焦点、リスクを最小化
     → 例：AAVEへのステーブルコインレンディング

[   ] パッシブインカム
     → 定期的な報酬、予測可能な利回り
     → 例：Lido経由のETHステーキング

[   ] 資本成長
     → より高いAPY目標、より多くの変動性を受け入れる
     → 例：DEXプールへの流動性提供

[   ] 分散化
     → 複数のチェーン/プロトコルに分散
     → 例：40%ステーキング、30%レンディング、30%LP

[   ] DeFiを探索
     → 学習モード、少額、ガイド付き体験
     → 例：2～3プロトコルで100～500ドルから開始
```

### ステップ2：リスク許容度

どの程度のリスクを受け入れられますか？
``` 
例：
  保守的         バランス           積極的
  ◀────────────────●──────────────────────▶
  低リスク           中程度              高リスク

あなたの位置：バランス

これは何を意味するか：
 ✓ より良いリターンのためにある程度の変動性を受け入れる
 ✓ 確立された+新しいプロトコルの組み合わせ（精査済み）
 ✓ 一部のロックアップ期間が許容される（30日未満）
 ✓ APYが10～20%変動する可能性があることを理解している
```

### ステップ3：時間軸

資金をどのくらいの期間展開する予定ですか？
``` 
例：
[   ] 短期（3か月未満）
    → 柔軟性が必要、ロックアップなし
    → 最大APYよりも流動性を優先する可能性

[●] 中期（3～12か月）
    → より良いレートのためにある程度のロックアップを受け入れられる
    → バランスの取れたアプローチ

[   ] 長期（1年以上）
    → 複利を最大化、ロックアップに抵抗がない
    → より低い取引頻度 = より低いガスコスト
```

### ステップ4：流動性の好み
いつでも引き出せることはどれほど重要ですか？
``` 
例：
[   ] 即座でなければならない（流動性トークンのみ）
    → stETH、rETH、aTokens - いつでもスワップ可能
    → 柔軟性のためにわずかに低いAPYを受け入れる可能性

[●] 柔軟（一部のキュー/遅延が許容可能）
    → 必要に応じてアンステークに1～7日待てる
    → より多くのプロトコルオプションが開かれる

[   ] コミット（より高いリターンのためのロックアップ）
    → より良いAPYのために30～90日ロックする意欲がある
    → 例：固定期間レンディング、ガバナンスステーキング
```

### ステップ5：チェーンと資産の好み
どのブロックチェーンと資産を好みますか？
``` 
例：
好みのチェーン：（1～3を選択）
[✓] Ethereum      [✓] Polygon      [   ] BNB Chain      [   ] Solana        [   ] Base         [   ] Cosmos

好みの資産：（1～5を選択）
[✓] ETH           [✓] USDC         [✓] USDT      [   ] BTC（ラップ済み） [   ] MATIC        [   ] SOL
```

### ステップ6：運用上の制約
運用上の好みや制限はありますか？
``` 
例：
取引あたりの最大ガスコスト：
[   ] 制限なし   [●] 20ドル   [   ] 10ドル   [   ] カスタム：$_____

1フローの最大ステップ数：
[   ] 制限なし   [●] 5ステップ   [   ] 3ステップ   [   ] 1ステップのみ

報酬決済の好み：
[●] USDTに自動変換（コスト効率が良い場合）
[   ] ネイティブトークンで保持（手動で変換）
[   ] 自動的に再ステーク（複利）

エクスポージャー制限（プロトコルごと）：
[   ] 制限なし   [●] 1つのプロトコルで最大50%   [   ] 最大30%
```

### ステップ7：経験レベル
DeFi経験をどのように表現しますか？
``` 
例：

[●] DeFi初心者
    → UIはより多くの説明と警告を表示
    → 推奨は保守的に傾く
    → ステップバイステップのガイダンスが有効

[   ] ある程度の経験（1～3プロトコルを使用）
    → バランスの取れた説明と自由
    → 推奨には中級オプションが含まれる

[   ] 上級者（5以上のプロトコルを使用、リスクを理解）
    → 最小限のサポート、高度な機能が有効
    → 推奨には最先端のプロトコルが含まれる
```

:::tip[注意] 

OROKAIはあなたの行動も監視します：
   • 取引の頻度 → 複雑さの推奨を調整
   • 使用されるプロトコルのタイプ → 提案を拡大/縮小
   • リスク警告への反応 → リスクスコアリングを洗練

:::

### 動的プロファイル適応

あなたのプロファイルは静的ではありません。AIはあなたの行動と市場状況から学習します：

> **ユーザー行動シグナル：**


- あなたは一貫して「より高いAPY」オプションを無視する

   → AI：安定性/セキュリティに向けて推奨をシフト

   → 更新：リスク許容度を「保守的」に低下

- あなたは問題なく10以上の取引を完了した

   → AI：より高度な機能を有効化

   → 更新：経験レベル → 「中級」

- あなたはより高いガスにもかかわらず常にEthereumを選択

   → AI：推奨で他のチェーンの優先度を下げる

   → 更新：チェーンの好み → 「ETH強く好む」

- あなたは毎回手動で報酬をUSDTに変換

   → AI：自動変換を有効にすることを提案

   → 更新：決済の好み → 「自動USDT」


> **市場状況シグナル：**


- Ethereumガスが取引あたり50ドル以上に急上昇

   → AI：推奨でPolygon/Baseを一時的にブースト

   → メッセージ：「Polygonを検討：同じプロトコル、95%低いガス」

- プロトコルXがセキュリティインシデント

   → AI：推奨から即座に削除

   → メッセージ：「プロトコルXはインシデントのため隔離されました」

- 新しいプロトコルが90日間の精査期間を通過

   → AI：プロファイルに一致する場合、提案に追加

   → メッセージ：「新しいオプション利用可能：プロトコルY」

- ステークされたプロトコルのAPYが30%低下

   → AI：通知+代替案を提案

   → メッセージ：「APYが2.2%に低下。プロトコルZ（3.1%）に移行しますか？」

:::warning[重要]

すべての適応は提案です。いつでも受け入れ、無視、または手動でオーバーライドできます。AIはあなたの署名なしに変更を実行できません。

:::


## プロファイルメカニクス

### 宣言的設定
UIベースのセットアップ（チェックボックス、スライダー、制限）。

### セキュリティポリシー
プロトコル/チェーンごとのエクスポージャーに対するハードリミット（例：ホワイトリスト）、スマートコントラクト権限の最小権限原則。

### プライバシー
プロファイルデータはパーソナライゼーションに使用され、エージェントが取引を実行することを承認しません。プライバシーポリシーに従って処理されます。

## モジュール出力

**「プロファイルカード」**を表示：目標 → リスクレベル → 好みのチェーン → 制約 → 決済通貨。

:::tip[ユーザーコントロール]

プロファイルは推奨のための入力として純粋に機能します – エージェントは決して自律的に行動せず、すべての取引には明示的なユーザー署名が必要です。

:::
