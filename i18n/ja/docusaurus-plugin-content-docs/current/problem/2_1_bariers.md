# DeFiへの参入障壁

## 新規ユーザーが直面する課題

### ウォレットと秘密鍵

新規ユーザーにとって、ウォレットを作成し、<mark>秘密鍵</mark>を開示したり紛失したりしてはならないことを理解することは、しばしば重大な障壁となります。さらに、<mark>シードフレーズ、バックアップ、フィッシング詐欺が</mark>大きな問題となっています。

### ガスコストとトークン

各ネットワークでは、取引手数料は異なるトークンで表され、動的に変化します。ユーザーは各チェーンで適切なガストークンを確保する必要があり、これが追加の手順（およびミス）を生み出します。

### クロスチェーンブリッジ

ネットワーク間での資産移転には、技術的および運用上のリスクを伴うツールが必要です（エラー、不正なパラメータ、類似した名前の資産の混同）。

### 複数ステップの操作

単純なアロケーションでも<mark>複数のステップが必要になる場合があります：</mark>スワップ → ブリッジ → デポジット/ステーク → クレーム/再ステーク。各段階には個別の取引、手数料、リスク、決定が含まれます。

## 結果

運用エラー（誤ったアドレス/チェーン、不適切なガストークンなど）の可能性が高く、不要なコスト、そして技術的でないユーザーによるプロセスの放棄。

:::warning[運用エラーの高い可能性]

技術的でないユーザーにとって、取り返しのつかない間違いを犯す可能性が高くなります。

:::

## **「苦痛の旅」 – 典型的なユーザーの経路**

ユーザーはETHのステーキングを開始したいと考えています。これが彼らが経験しなければならないことです：

ステップ1：ウォレットの選択
```
├─ Metamask vs. Rabby vs. Rainbow vs. Ledger vs. Trezor？
├─ 「どれが安全？」
└─ 決定：30～60分のリサーチ → Metamask（最も人気）
```
ステップ2：インストールとシードフレーズ
```
├─ 12個のランダムな単語：「voyage spatial quantum...」
├─ 警告：「決して共有せず、スクリーンショットを撮らないでください」
├─ ストレス：「紛失したら？誰かに盗まれたら？」
└─ ユーザーの25%がここで離脱（出典：Metamask調査2023年）
```

ステップ3：ETHの購入
```
├─ CEX経由の場合：KYC（1～3日）+ 送金（手数料5～15ドル）
├─ DEX経由の場合：すでにガス用のETHが必要（卵が先か鶏が先か問題）
└─ 平均時間：2～5日
```

ステップ4：Lidoの理解
```
├─ 「stETHとは？」 → 30分のリサーチ
├─ 「rETH、cbETHとの違いは？」 → 混乱
└─ 「資金を失う可能性は？」 → FUD（恐怖、不確実性、疑念）
```

ステップ5：LidoへのウォレットXconnect
```
├─ ポップアップ：「Lido.fiがあなたのウォレットに接続したいです」
├─ フィッシングの恐怖：「これは本物のLido？」
└─ 検証：URL、ロゴ、コミュニティを確認
```

ステップ6：コントラクトの承認
```
├─ ポップアップ：「LidoがあなたのETHを使用することを許可 - 無制限」
├─ 「無制限？！危険だ！」
├─ コスト：3～8ドルのガス手数料（初回、驚き）
└─ ユーザーの15%がここで離脱（出典：Etherscanデータ）
```

ステップ7：ステーク取引
```
├─ 2回目の取引、2回目のガス手数料（5～12ドル）
├─ 「推定時間：15秒」 → 実際には3分（Ethereumの混雑）
└─ 成功...それとも？
```

ステップ8：検証
```
├─ 「stETHを受け取った？」 → Metamaskに手動でトークンを追加する必要がある
├─ 「いつ報酬を受け取る？」 → リサーチ：「毎日発生、残高に表示」
└─ 「どうやって引き出す？」 → さらにリサーチ：「stETH → ETHをスワップまたはアンステークキュー」
```


> 合計時間：3～7日（KYCあり）または4～8時間（KYCなし）

> ステップ数：8つの主要ステップ + 約20のマイクロ決定

> 離脱可能ポイント：5

> 成功率（完了率）：約35～40%
