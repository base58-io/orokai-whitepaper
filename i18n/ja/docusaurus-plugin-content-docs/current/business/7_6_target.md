# ターゲット顧客セグメントと獲得チャネル

## 顧客セグメント

OROKAIは、それぞれ独自のニーズ、行動、獲得戦略を持つ複数の異なる顧客セグメントにサービスを提供します。このセクションでは、ターゲットセグメントを定義し、各セグメントに獲得チャネルをマッピングし、フェーズごとの市場参入戦略を概説します。

### 顧客セグメンテーションフレームワーク
> アクティビティレベル（低 → 高）

> 技術的洗練度（初心者 → エキスパート）

> 資本サイズ（リテール → 機関）

> 主要ユースケース（エントリー → アドバンスド）

### セグメント1

> #### 暗号資産好奇心層（エントリーポイント）

#### プロフィール
```
デモグラフィック：
├─ 年齢：25～45歳
├─ 収入：年間5万～15万ドル
├─ 所在地：グローバル（焦点：米国、EU、アジア）
├─ テクノロジーに精通しているが暗号資産ネイティブではない
└─ 暗号資産について聞いたことがあるが、複雑さに圧倒されている

資本：
├─ 初期エントリー：500～5,000ドル
├─ 潜在TVL：5,000～2万ドル
└─ 成長可能性：→ ベーシックまたはアクティブセグメント

行動：
├─ リスクなしでDeFiを「試したい」
├─ 手取り足取りのサポートが必要（教育、シンプルなUX）
├─ カード優先（馴染みのあるメンタルモデル）
└─ 初期探索後に休眠状態になる可能性

ペインポイント：
├─ 「DeFiは複雑すぎる」
├─ 「中央集権的な取引所を信頼していない」
├─ 「秘密鍵を管理したくない」
└─ 「どのプロトコルが安全かわからない」
```
:::tip[バリュープロポジション]
5分で暗号資産の使用を開始—ウォレット設定不要、専門用語なし、カードとシンプルなスワップだけ。私たちが複雑さを処理します。
:::
> 主要機能：
- ゼロセットアップウォレット（複雑さを抽象化）
- 主要エントリーとしてのカード（取引ではなく支出）
- クレジットカードでのオンランプ（馴染みのあるフロー）
- キュレートされたプロトコル（選択の麻痺なし）
- 教育コンテンツ（自信を構築）

#### 獲得戦略
> 主要チャネル：
- 有料ソーシャル（Meta/TikTok）→ ライフスタイルコンテンツ、技術的ではない
- インフルエンサーパートナーシップ → フィンテックYouTuber、暗号資産マキシマリストではない
- コンテンツマーケティング → 「初心者のためのDeFi」SEO
- カード優先キャンペーン → 「現金のように暗号資産を使う」

> メッセージング：
- 機能よりもシンプルさ
- 利回りよりも安全性
- 革新（ブロックチェーン）よりも馴染み（カード、アプリ）
- 目的地ではなく、エントリーポイント

### セグメント2

> #### DeFi初心者（アクティブユーザー）

#### プロフィール
```
デモグラフィック：
├─ 年齢：25～40歳
├─ 収入：年間7.5万～20万ドル
├─ 以前にCEX（Coinbase、Binance）を使用したことがある
├─ 暗号資産の基本を理解、DeFiは初心者
└─ CEXが提供するよりも高い利回りを求めている

資本：
├─ 初期エントリー：5,000～5万ドル
├─ 潜在TVL：2万～10万ドル
└─ 成長可能性：→ パワーセグメント

行動：
├─ 積極的にDeFiエクスポージャーを求めている
├─ 学ぶ意欲があるがガイダンスが必要
├─ カードとオンチェーン機能の両方を使用
├─ 週次でアプリをチェック、月に5～10回取引
└─ AI推奨に良好に反応

ペインポイント：
├─ 「DeFiプロトコルが多すぎる、どれを信頼すべきか？」
├─ 「ガス手数料が混乱する」
├─ 「以前に悪いブリッジでお金を失った」
└─ 「利回りが欲しいが、詐欺に遭いたくない」
```
:::tip[バリュープロポジション]
DeFi利回りを安全に獲得—私たちが最高のプロトコルをキュレートし、ガス最適化を処理し、AIでガイドします。あなたは完全な制御を保持します。
:::
> 主要機能：
- AIエージェント（キュレートされた戦略）
- 自動クレーム（受動的収入の利便性）
- マルチチェーン（手動ブリッジなし）
- 透明な手数料（サプライズなし）
- 安全第一（ホワイトリスト、監査）

#### 獲得戦略
> 主要チャネル：
- コンテンツマーケティング → 「2025年最高のDeFi利回り」比較
- アフィリエイトプログラム → DeFi教育者、YouTuber
- 有料検索 → 「DeFi利回りアグリゲーター」キーワード
- コミュニティ（Discord/Telegram）→ 教育イベント、AMA
- パートナーシップ → ウォレットと統合（MetaMask、Rainbow）

> メッセージング：
- 利回り機会 + 安全性
- シンプルさ（生のDeFiプロトコル vs）
- ノンカストディアル（CEX vs）
- AIガイド付き（差別化）

```
デモグラフィック：
├─ 年齢：28～45歳
├─ 収入：年間15万～50万ドル（または暗号資産富裕層）

資本：
├─ 初期エントリー：5万～50万ドル
├─ 潜在TVL：10万～100万ドル
└─ 成長可能性：→ ホエールセグメント（一部）

行動：
├─ 洗練された戦略（マイグレーション、クロスチェーンアービトラージ）
├─ 自動化を使用（自動クレーム、リバランス）
├─ 高い取引頻度（月20～50回）
├─ 大きな支出のためのカード（月3,000～1万ドル）
└─ アフィリエイトプログラムでアクティブ（友人を募集）

ペインポイント：
├─ 「5つのチェーンにわたる10のウォレットを管理するのは疲れる」

:::tip[バリュープロポジション]
1つのダッシュボードからDeFiポートフォリオ全体を管理—戦略を自動化し、利回りを最適化し、週に数時間を節約します。
:::
> 主要機能：
- 高度な分析（パフォーマンス追跡）
- AI（リバランス、利回り最適化）
- マルチチェーン集約（すべてを1か所で見る）
- 優先サポート（速い応答時間）

> メッセージング：
- 効率性（時間を節約）
- 最適化（AIを介したより高いリターン）
- 統一ダッシュボード（複数のアプリをジャグリング vs）

```

├─ 複雑な戦略（マルチシグ、コンプライアンスニーズ）

├─ 「コンプライアンスのための監査証跡が必要」
├─ 「ロールベースアクセスを持つマルチシグサポートが必要」
├─ 「カスタム手数料契約が必要」
└─ 「専任のアカウント管理が必要」

> 主要機能：
- マルチシグウォレットサポート
- APIアクセス + ウェブフック（カスタム統合）
- コンプライアンスレポート（取引ログ）

> 主要チャネル：

- カンファレンス（VIPディナー、非公開会議）
- パートナーシップ（機関カストディアンと統合）
- 紹介（既存のホエール顧客 → 他者）
- ソートリーダーシップ（リサーチレポート、ホワイトペーパー）

> メッセージング：
- セキュリティとコンプライアンス（優先事項＃1）
- 機関グレードインフラストラクチャ
- 柔軟性（カスタム条件）
- ノンカストディアル（制御を保持）

### セグメント5

> #### B2Bパートナー

#### プロフィール
```
エンティティタイプ：
├─ フィンテックアプリ（DeFi機能を追加したい）
├─ ウォレット（利回り/カード機能を追加したい）
├─ ネオバンク（暗号資産統合が必要）
├─ DeFiプロトコル（ユーザーのUXを改善したい）
└─ 暗号資産ネイティブビジネス（カード/オンランプが必要）

資本：
├─ 直接TVLなし（ユーザーを連れてくる）
├─ 潜在性：パートナーあたり1,000～10万ユーザー
└─ 収益：卸売価格または収益分配

行動：
├─ 長い評価サイクル（6～12か月）
├─ カスタム統合が必要（API、SDK、ホワイトラベル）
├─ 共同ブランディングまたは見えないOROKAI（バックエンドのみ）が必要
└─ 定着性（統合後、切り替えが困難）

ペインポイント：
├─ 「社内でDeFiインフラストラクチャを構築するのは高すぎる」
├─ 「DeFiを提供したいがカストディリスクは避けたい」
├─ 「ユーザーが利回りを求めているが、アプリがサポートしていない」
└─ 「ユーザーのためにフィアットオン/オフランプとカードが必要」
```
:::tip[バリュープロポジション]
サービスとしてのホワイトラベルDeFiインフラストラクチャ—数年ではなく数週間でDeFi機能をローンチ。ノンカストディアル、コンプライアント、完全にブランド化。
:::

#### 獲得戦略

> 主要チャネル：
- 直接販売（フィンテック、ウォレット、プロトコルへのアウトリーチ）
- パートナーシップチーム（専任BD）
- カンファレンス（API/開発者焦点のトラック）
- 開発者ドキュメント（インバウンドAPI関心を引き付ける）
- ケーススタディ（成功した統合をショーケース）

> メッセージング：
- 市場投入までの速度（社内構築 vs）
- ノンカストディアル（規制負担を軽減）
- 収益機会（取引手数料の分配）
- ターンキーソリューション（バックエンド + フロントエンド準備完了）

- ターゲティング：暗号資産コンテンツ視聴者、金融教育
