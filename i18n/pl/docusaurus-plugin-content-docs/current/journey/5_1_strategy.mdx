# Wybór strategii i pierwsza alokacja

## Proces sześciokrokowy

Pierwsza alokacja każdego użytkownika odbywa się zgodnie z przewodnikiem drzewa decyzyjnego opartym na jego profilu i preferencjach.

### Krok 2 – AI pokazuje dopasowane opcje
```

│  │

```

│  │

│  │  └─ Powrót do Kroku 2
│  │
│  ├─ „Muszę najpierw dostosować profil"
│  │  ├─ Modyfikuj cele/ryzyko/preferencje

### Kluczowe punkty decyzyjne, gdzie UŻYTKOWNIK kontroluje wynik

| Punkt decyzyjny | Opcje użytkownika | Rola OROKAI |
|----------------|-------------|-------------|
| **Konfiguracja profilu** | Cele, ryzyko, horyzont, preferencje | Sugeruje domyślne, użytkownik decyduje |
| **Wybór strategii** | Wybierz rekomendowaną lub alternatywy | Pokazuje opcje, użytkownik wybiera |
| **Dostosowanie** | Dostosuj alokacje, mieszaj strategie | Przygotowuje przepływ, użytkownik zatwierdza |
| **Akceptacja kosztów** | Kontynuuj lub czekaj na lepsze warunki | Pokazuje koszty, użytkownik decyduje |
| **Każdy podpis** | Podpisz lub odrzuć każdą transakcję | Przygotowuje tx, użytkownik podpisuje |
| **Zakres zatwierdzenia** | Ograniczone vs nieograniczone uprawnienia | Rekomenduje ograniczone, użytkownik wybiera |
| **Po alokacji** | Monitoruj, claimuj, migruj, wyjdź | Sugeruje działania, użytkownik wykonuje |

:::tip[Podstawowa zasada]
W każdym punkcie decyzyjnym TY masz ostatnie słowo.  
OROKAI informuje, przygotowuje i prowadzi — TY decydujesz i wykonujesz.
:::

:::warning[Brak „najlepszej egzekucji"]
OROKAI nie gwarantuje najlepszej ceny; pokazujemy koszty i slippage przed podpisaniem.
:::
