> あなたのプロファイルを分析

   - 目標：資本保全 / パッシブインカム / 成長
   - リスク許容度：保守的 / バランス / 積極的
   - 時間軸：短期 / 中期 / 長期
   - 好み：チェーン、資産、ロックアップ制約
   - 経験レベル：初心者 / 中級 / 上級

> プロトコルをフィルタリング

   - ホワイトリスト：監査済み、精査済みのプロトコルのみを表示
   - リスクスコアリング：TVL、監査、稼働時間、インシデントに基づく
   - マッチング：宣言されたプロファイルと整合
   - 除外：隔離/高リスクオプションを自動的に除外

> オプションを表示

   - オプションA：あなたのプロファイルに「最適」
   - オプションB：代替案（異なるリスク/リターンバランス）
   - オプションC：代替案（異なるチェーン/プロトコル）
   - それぞれに：期待APY、コスト、リスク、ステップ

> 理由を説明（「理由コード」）

   - 「推奨理由：[あなたの目標] + [低リスク] + [高流動性]」
   - 「代替理由：[高APY] だが [ロックアップ期間]」
   - 「回避理由：[最近のインシデント] / [低流動性] / [高コスト]」

> モニタリングと調整提案

   - 「APYが2%低下 → マイグレーションを検討？」
   - 「新しいプロトコルがあなたのプロファイルに一致 → レビュー？」
   -  「ガス価格が低い → リバランスの良いタイミング？」
   -  あなたが変更を承認（AIは実行しない）

> 金融助言を提供しない

   - AIの提案は情報提供であり、投資助言ではありません
   - あなた自身の決定に責任があります

> リターンを保証しない

   - すべての利回りは変動し、プロトコルに依存します
   - AIは将来の市場状況を予測できません

> 取引を実行しない

   - AIは取引インテントを準備します
   - あなた自身のウォレットですべての取引に署名する必要があります

> あなたの資金へのアクセスを持たない

   - AIはあなたのお金を動かせません
   - ノンカストディアルモデルを維持

> デューデリジェンスを置き換えない

   - 常にプロトコル文書を読み、リスクを理解してください
   - AIは支援するツールであり、調査の代替ではありません


:::tip[透明性と説明可能性：]
- すべての推奨は「なぜこれ？」理由コードを表示
- どの要因が提案に影響したかを確認できます
- いつでもプロファイルを調整可能（AIが再評価）
- 提案とあなたの行動の完全な履歴（監査証跡）
:::

## 「情報提供のみ」が重要な理由

### 法的および規制

| AIが「助言的」である場合 | OROKAIの「情報提供」アプローチ |
|----------------------|-----------------------------------|
| 投資顧問ライセンスが必要（SEC、FCA、MAS...） | データとツールを提供するソフトウェア |
| 受託者義務（顧客の最善の利益のために行動する必要がある） | ユーザーが自身の決定を下す |
| 損失に対する責任（「悪いアドバイス」） | 開示：変動するリターン、ユーザー責任 |
| 義務的な適合性評価 | パーソナライゼーションのためのオプションプロファイル |
| 継続的なモニタリング義務 | 機能としてのモニタリング、義務ではない |
| 詳細なコンプライアンスレポート | 標準ソフトウェアToSとプライバシーポリシー |

### 規制の先例：

- **Robinhood「Learn」**：教育コンテンツ、助言ではない → RIAライセンス不要
- **CoinGeckoアラート**：「BTCが5%下落」通知 → 情報提供、助言ではない
- **TradingViewインジケーター**：テクニカル分析ツール → ユーザーが解釈、助言ではない
- **OROKAI AI**：理由付きプロトコル提案 → ユーザーが決定、助言ではない

## 範囲と制限

### 投資助言なし
推奨は<mark>情報提供の性質を持ちます。</mark>決定と承認はユーザーに留まります。

### リターン/価格保証なし
リターンとレートは変動し、プロトコルと市場に依存します。<mark>エージェントは最良価格または実行を保証しません。</mark>

### ノンカストディアル
<mark>エージェントは鍵へのアクセスを持たず</mark>、取引を実行しません。準備して説明するモデルで動作します。

## セキュリティコントロール（「ガードレール」）

### プロトコルホワイトリスト
プロトコル/ブリッジ/DEXのホワイトリスト、プロトコルとチェーンごとのエクスポージャー制限。

### 署名前検証
ステップのリスト、コスト（ガス/スリッページ/手数料）、<mark>必要なスマートコントラクト権限。</mark>

### 異常検出
リスクシグナル（清算、流動性、インシデント） → 一時停止して警告。

### 権限取り消し
承認を取り消し/制限するクイックリンク。

### コンプライアンス
地理的制限、制裁措置、パートナー規則（オン/オフランプ、カード）は彼らの側で処理。UIで制限を強制。

## 透明性と説明可能性

### 理由コード
各提案には理由コード、仮定のリスト、リスク要因があります。

### 決定ログ
何を、いつ、どのような根拠で提案したか – ユーザーが利用可能。

### ユーザーコントロール
<mark>ユーザーはパーソナライゼーションを無効化</mark>またはプロファイルをリセットできます。

:::warning[重要な免責事項]

**AI Agent OROKAI**は、ユーザーの宣言されたプロファイルに沿った情報と提案を提供します。これは投資助言ではありません。すべての操作には、ユーザーのウォレットでの意識的な署名が必要です。リターンは変動し、保証されません。

:::
