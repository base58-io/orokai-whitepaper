# ユニットエコノミクス

ユニットエコノミクスは、<mark>ユーザーあたりの収益性</mark>と持続可能なビジネスへの全体的な道筋を定義します。このセクションでは、OROKAIのユーザーレベルでの収益とコストをモデル化し、主要な収益性レバーを特定し、損益分岐点シナリオを予測します。

## ユーザーあたりの収益構造（簡易モデル）

### 基本式

ユニット利益 = ARPU（ユーザーあたり平均収益）- CAC（顧客獲得コスト）- CPS（サービス提供コスト）

ここで：
- ARPU = アクティブユーザーあたりの月次平均収益
- CAC = ユーザー獲得のための一回限りのコスト（マーケティング、オンボーディング）
- CPS = ユーザーにサービスを提供するための継続的な月次コスト（インフラストラクチャ、サポート）

収益性が達成される時：
ユニット利益 > 0（ユーザーライフタイムにわたって）

### ARPU：ユーザーあたり平均収益

ARPUは、ユーザータイプとアクティビティレベルによって大きく異なります。

### ARPUコンポーネント（月次）

> ARPU源：
- オンチェーン操作（スワップ、ブリッジ、マイグレーション）
- ステーキング自動化（自動クレーム手数料）
- カード取引（支出）
- オン/オフランプ（フィアット変換）
- ガスマークアップ（すべての取引）

> 式：
ARPU = Σ（アクティビティ_i × 手数料_i × 頻度_i）

> ここで：
- アクティビティ_i = 操作のタイプ（スワップ、ステーク、カードなど）
- 手数料_i = その操作に対するOROKAIの手数料
- 頻度_i = ユーザーが月にその操作を実行する頻度

### ユーザーセグメントとARPUティア

#### セグメント1：カジュアルユーザー（非アクティブ）
```
プロフィール：
├─ サインアップ、初回オンランプ実施
├─ 暗号資産を保有しているが取引しない
├─ カード使用なし、ステーキングなし
└─ 年に1～2回のスワップの可能性

月次アクティビティ：
├─ スワップ：0.1/月 × 5ドル手数料 = 0.50ドル
├─ カード：0ドル
├─ ステーキング：0ドル
├─ オンランプ：0ドル（既にオンボード済み）
└─ ガスマークアップ：約0.10ドル

ARPU：月0.60ドルまたは年7.20ドル

頻度：ユーザーの約40%（休眠/非アクティブ）
```

#### セグメント2：ベーシックユーザー（低アクティビティ）
```
プロフィール：
├─ 時折のスワップ（様子見）
├─ 小規模なステーキングポジション（手動クレーム）
├─ まれなカード使用
└─ 月次でアプリをチェック

月次アクティビティ：
├─ スワップ：2/月 × 5ドル手数料 = 10ドル
├─ カード：200ドル支出 × 0.3% = 0.60ドル
├─ ステーキング：手動（ガスのみ）= 0.30ドル
├─ オンランプ：0ドル
└─ ガスマークアップ：約2ドル

ARPU：月12.90ドルまたは年154.80ドル

頻度：ユーザーの約30%
```

#### セグメント3：アクティブユーザー（中程度のアクティビティ）
```
プロフィール：
├─ 定期的なスワップ（ポートフォリオのリバランス）
├─ 中規模のステーキング（1万～5万ドルのTVL）
├─ 二次的な支出方法としてのカード
└─ 週次でアプリをチェック

月次アクティビティ：
├─ スワップ：8/月 × 8ドル手数料 = 64ドル
├─ カード：1,000ドル支出 × 0.3% = 3ドル
├─ ステーキング（自動クレーム）：月50ドル報酬 × 8% = 4ドル
├─ ブリッジ：四半期に1回（÷3）= 1.67ドル
└─ ガスマークアップ：約8ドル

ARPU：月80.67ドルまたは年968ドル

頻度：ユーザーの約20%
```

#### セグメント4：パワーユーザー（高アクティビティ）
```
プロフィール：
├─ 毎日のトレーダー/リバランサー
├─ 大規模なステーキングポジション（10万～50万ドルのTVL）
├─ 主要な支出方法としてのカード
├─ アフィリエイトプログラムでアクティブ
└─ AI自動化機能を使用

月次アクティビティ：
├─ スワップ：30/月 × 10ドル手数料 = 300ドル
├─ カード：5,000ドル支出 × 0.3% = 15ドル
├─ ステーキング（自動クレーム）：月500ドル報酬 × 8% = 40ドル
├─ ブリッジ：2/月 × 5ドル = 10ドル
├─ マイグレーション：四半期に1回（÷3）= 7ドル
└─ ガスマークアップ：約35ドル

ARPU：月407ドルまたは年4,884ドル

頻度：ユーザーの約8%
```

#### セグメント5：ホエール（機関/高純資産）
```
プロフィール：
├─ 数百万のTVL（100万ドル以上）
├─ 頻繁な大規模取引
├─ ビジネス経費のためのカード
├─ 複雑な戦略（マイグレーション、クロスチェーン）
└─ 専任のアカウント管理

月次アクティビティ：
├─ スワップ：50/月 × 50ドル手数料（より大きいサイズ）= 2,500ドル
├─ カード：20,000ドル支出 × 0.3% = 60ドル
├─ ステーキング（自動クレーム）：月10,000ドル報酬 × 8% = 800ドル
├─ ブリッジ：5/月 × 20ドル = 100ドル
├─ マイグレーション：2/月 × 50ドル = 100ドル
└─ ガスマークアップ：約150ドル

ARPU：月3,710ドルまたは年44,520ドル

頻度：ユーザーの約2%
```

### ブレンドARPU計算
```
加重平均ARPU（合計10万ユーザー）：

├─ カジュアル（40%）：40,000ユーザー × 0.60ドル = 月24,000ドル
├─ ベーシック（30%）：30,000ユーザー × 12.90ドル = 月387,000ドル
├─ アクティブ（20%）：20,000ユーザー × 80.67ドル = 月1,613,400ドル
├─ パワー（8%）：8,000ユーザー × 407ドル = 月3,256,000ドル
└─ ホエール（2%）：2,000ユーザー × 3,710ドル = 月7,420,000ドル

月次総収益：12,700,400ドル
ブレンドARPU：月127ドルまたは年1,524ドル

注：これはアフィリエイト支払い前の総収益です
```

### CAC：顧客獲得コスト

#### 獲得チャネルとコスト
```
チャネル1：アフィリエイトプログラム（主要）
├─ 前払いCAC：0ドル（収益に対してのみ支払い）
├─ 継続コスト：ユーザー収益の約15%（ライフタイム）
├─ 実効CAC（1年目に償却）：ユーザーあたり195ドル
└─ 最適：スケーラブルで予測可能な成長

チャネル2：有料広告（Google/Meta）
├─ 前払いCAC：サインアップあたり80～150ドル
├─ コンバージョン率：30～50%（サインアップ → 最初の取引）
├─ 実効CAC：アクティブユーザーあたり160～300ドル
├─ 継続コスト：0ドル（一回限り）
└─ 最適：急速な成長スパート、地理的拡大

チャネル3：コンテンツマーケティング（SEO/ブログ）
├─ 前払いCAC：サインアップあたり20～40ドル（償却コンテンツコスト）
├─ コンバージョン率：50～60%（高意図トラフィック）
├─ 実効CAC：アクティブユーザーあたり33～80ドル
├─ 継続コスト：最小限（コンテンツは常緑）
└─ 最適：長期的な持続可能な成長

チャネル4：パートナーシップ（B2B/統合）
├─ 前払いCAC：変動（パートナーシップあたり0～5万ドル）
├─ ユーザーあたりCAC：10～50ドル（パートナーサイズに依存）
├─ コンバージョン率：60～80%（事前資格のあるユーザー）
├─ 実効CAC：アクティブユーザーあたり13～83ドル
└─ 最適：機関/ホエール獲得

チャネル5：オーガニック/バイラル（口コミ）
├─ 前払いCAC：0ドル
├─ 継続コスト：製品品質 + サポート
├─ 実効CAC：ユーザーあたり5～15ドル（サポート/インフラのみ）
└─ 最適：長期的、複利成長
```

**ブレンドCAC（ターゲットミックス）：**
```
獲得ミックス（1～2年目）：
├─ アフィリエイト：ユーザーの60% → 195ドル × 0.60 = 117ドル
├─ 有料広告：ユーザーの20% → 230ドル × 0.20 = 46ドル
├─ コンテンツ：ユーザーの10% → 57ドル × 0.10 = 5.70ドル
├─ パートナーシップ：ユーザーの5% → 48ドル × 0.05 = 2.40ドル
└─ オーガニック：ユーザーの5% → 10ドル × 0.05 = 0.50ドル

ブレンドCAC：ユーザーあたり171.60ドル

注：これは一回限りのコストです（アフィリエイトを除く、継続的な%）
```

**各ユーザーにサービスを提供するための継続的なコスト：**

```
├─ アプリ配信、静的アセット

モニタリング/可観測性：
├─ ログ、メトリクス、トレース

平均：ユーザーあたり月約2.50ドル
```

### サポートコスト（変動）
```
カスタマーサポート：

カジュアル/ベーシックユーザー（ユーザーの70%）：
├─ まれなサポートチケット（月約0.1チケット）
├─ チケットあたりコスト：5ドル（自動化 + ティア1）
└─ 月次：ユーザーあたり0.50ドル

アクティブ/パワーユーザー（ユーザーの28%）：
├─ 中程度のサポート（月約0.5チケット）
├─ チケットあたりコスト：8ドル（ティア1 + 一部ティア2）
└─ 月次：ユーザーあたり4ドル

ホエールユーザー（ユーザーの2%）：
├─ ハイタッチサポート（月約2チケット）
├─ チケットあたりコスト：15ドル（ティア2 + 専任）
└─ 月次：ユーザーあたり30ドル

ブレンドサポートコスト：
├─ 70% × 0.50ドル = 0.35ドル
├─ 28% × 4ドル = 1.12ドル
└─ 2% × 30ドル = 0.60ドル
──────────────────────
合計：ユーザーあたり月約2.07ドル
```

### セグメントレベルの収益性

**どのユーザータイプが収益性がありますか？**

| セグメント | ARPU（純額） | CAC（1年目償却） | CPS | ユニット利益 | 収益性？ |
|---------|------------|-------------------|-----|-------------|-------------|
| **カジュアル** | 0.60ドル | 14.30ドル | 7.57ドル | **-21.27ドル** | ❌（損失リーダー） |
| **ベーシック** | 12.90ドル | 14.30ドル | 7.57ドル | **-8.97ドル** | ❌（限界的） |
| **アクティブ** | 80.67ドル | 14.30ドル | 7.57ドル | **+58.80ドル** | ✅（収益的） |
| **パワー** | 407ドル | 14.30ドル | 7.57ドル | **+385.13ドル** | ✅✅（高収益） |
| **ホエール** | 3,710ドル | 14.30ドル | 30ドル | **+3,665.70ドル** | ✅✅✅（極めて高収益） |

**洞察：**

1. **カジュアル/ベーシックユーザーは1年目は非収益的**
   - しかし：時間をかけてアクティブ/パワーに転換する可能性（LTVが重要）
   - 戦略：これらのセグメントのCACを最小化（アフィリエイト優先、有料広告ではない）

2. **アクティブユーザーがスイートスポット**
   - ユーザーの20%が利益の30%を生成
   - このセグメントでの獲得に焦点

3. **パワー/ホエールユーザーが収益性を牽引**
   - ユーザーの10%が利益の70%を生成
   - ハイタッチサービスが正当化される（ホエールには月30ドルのCPSの価値がある）

## 収益性レバー

### レバー1：ARPUの増加
```
戦略：
├─ より高いアクティビティを促進（プッシュ通知、ゲーミフィケーション）
├─ プレミアム機能のアップセル（自動クレーム、AI戦略）
├─ カード使用の増加（マーケティング、報酬）
├─ クロスセル（ユーザーがスワップのみの場合、ステーキングを紹介）
└─ 新しい収益ストリームのローンチ（サブスクリプション、APIアクセス）

影響：
├─ +10% ARPU → ユーザーあたり月+10.80ドル
└─ 総利益：103.3M ドル → 116.3M ドル（+12.6%）✅

実現可能性：中（製品開発 + マーケティングが必要）
```

### レバー2：CACの削減
```
戦略：
├─ 有料広告からアフィリエイトプログラムへシフト（低CAC）
├─ コンテンツSEOの改善（オーガニックトラフィック）
├─ 紹介インセンティブ（バイラル成長）
├─ パートナーシップ（より低コストで資格のあるリード）
└─ コンバージョンファネルの改善（ドロップオフを削減）

影響：
├─ -20% CAC（171ドル → 137ドル）→ ユーザーあたり月-2.86ドル
└─ 総利益：103.3M ドル → 106.7M ドル（+3.3%）✅

実現可能性：高（運営改善）
```

### レバー3：CPS（インフラストラクチャ）の削減
```
戦略：
├─ より良いRPC/クラウドレートの交渉（ボリューム割引）
├─ RPC使用の最適化（キャッシング、バッチコール）
├─ 重要なインフラストラクチャのセルフホスト（SaaS vs）
├─ サポートの自動化（AIチャットボット、より良いドキュメント）
└─ より多くのユーザーに固定費をスケール（ユーザーベースを成長）

影響：
├─ -20% CPS（7.57ドル → 6.06ドル）→ ユーザーあたり月+1.51ドル
└─ 総利益：103.3M ドル → 121.4M ドル（+17.5%）✅

実現可能性：高（エンジニアリング + スケール）
```

### レバー4：ユーザーミックスの改善（セグメントシフト）
```
戦略：
├─ マーケティングでアクティブ/パワー/ホエールユーザーをターゲット
├─ リードを資格認定（カジュアルなサインアップを阻止）
├─ カジュアル → ベーシック → アクティブを育成（オンボーディング、教育）

影響（40/30/20/8/2から30/25/25/15/5へミックスをシフト）：

├─ ブレンドARPU：月107.95ドル

後：
├─ カジュアル（30%）：30% × 0.60ドル = 0.18ドル
├─ ベーシック（25%）：25% × 12.90ドル = 3.23ドル
├─ アクティブ（25%）：25% × 80.67ドル = 20.17ドル

└─ ホエール（5%）：5% × 3,710ドル = 185.50ドル
──────────────────────
新ブレンドARPU：月270.13ドル（+150%！）✅✅

総利益：103.3M ドル → 315M ドル（+205%）✅✅✅

実現可能性：中（ターゲット獲得 + 維持が必要）
```

### レバー5：チャーンの削減（ライフタイムの増加）
```
現在の仮定：ユーザーライフタイム = 平均24か月

チャーン削減戦略：

チャーン率目標：
├─ 1年目：30%（業界標準）
├─ 2年目：20%（改善）

```

```
└─ ユニット利益：月86.08ドル → 年間総額103.3M ドル

変数：CAC（±20%）
```

### 損益分岐点分析

**OROKAIはどの規模で収益的になりますか？**
```
固定費：月30万ドル
ユーザーあたり変動費：月4.57ドル（インフラ + サポート）
ARPU（アフィリエイト後純額）：月107.95ドル
CAC（1年目償却）：月14.30ドル

月次損益分岐点：

固定費 ÷（ARPU - 変動費 - CAC）= 必要ユーザー数
30万ドル ÷（107.95ドル - 4.57ドル - 14.30ドル）= 30万ドル ÷ 89.08ドル = 3,368ユーザー

損益分岐点：約3,400アクティブユーザー

3,400ユーザー時：
├─ 収益：3,400 × 107.95ドル = 月367kドル
├─ 変動費：3,400 × 4.57ドル = 月15.5kドル
├─ 固定費：月300kドル
├─ CAC（償却）：3,400 × 14.30ドル = 月48.6kドル
└─ 利益：367k - 15.5k - 300k - 48.6k = 月約3kドル ✅（損益分岐点）

3,400ユーザーまでのタイムライン：
├─ 積極的成長：4～5か月目
├─ 中程度の成長：6～8か月目
└─ 保守的な成長：9～12か月目

判定：OROKAIはローンチ後4～12か月以内に収益性に到達可能
```

### 要約：ユニットエコノミクスの健全性

OROKAIユニットエコノミクス評価：

> 強いブレンドARPU：月108ドル（業界平均50～80ドルと比較して健全）

> 管理可能なCAC：172ドル（2か月で回収可能）

> 低CPS：7.57ドル（規模で改善）

> 速いペイバック：2か月（CACが迅速に回収）

> 高LTV:CAC比率：1年目で6:1（1,033ドルLTV ÷ 172ドルCAC）

> スケーラブル：規模の経済がマージンを30% → 50%以上に改善

> 複数のレバー：ARPU、CAC、CPS、ミックスを通じて収益性を改善可能

> 早期損益分岐点：3,400ユーザーで収益的（約4～12か月目）

> リスク：
- カジュアル/ベーシックユーザーは非収益的（転換または回避が必要）
- パワー/ホエールユーザーへの高依存度（10%が利益の70%を牽引）
- アフィリエイトコストの恒久的な15%ドラッグ（ただし成長を可能にする）
- チャーンリスク（24か月以上のライフタイムを維持する必要）

判定：収益性への明確な道筋を持つ強力なユニットエコノミクス。
