# How It Works (User Journey)

OROKAI <mark>simplifies DeFi entry:</mark> from on-ramp through "zero-setup wallet," strategy selection, first allocation, to monitoring and potential "one-click" migrations between protocols and chains - with full user control (self-custody). 

Crypto exchanges are executed by external DEX from the list of approved integrations; fiat/card settlements are handled by licensed partners. <mark>Protocol returns are variable and not guaranteed;</mark> every operation is signed by the user in their wallet.
