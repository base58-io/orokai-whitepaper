# 「ゼロウォレットセットアップ」 – ウォレット作成不要の投資

## ウォレットの抽象化、カストディではない

### 抽象化、カストディではない

ウォレットがユーザー側で作成される（例：デバイスID/メールにリンクされたスマートウォレット/MPC）「ゼロセットアップ」モードを提供しますが、<mark>鍵はOROKAIによって保管されません。</mark>

### 摩擦のないオンボーディング

ユーザーは、ライセンス取得済みパートナーを通じたオンランプで開始し、その後、手動でシードフレーズを設定することなく、数ステップで最初の取引に署名できます（ユーザー側で鍵をエクスポート/回復するオプションは保持）。

### 完全な制御

すべての操作には意識的な承認が必要です。ユーザーはいつでも、エコシステムがサポートする別のウォレットに資産を転送できます。

### 「ゼロセットアップ」はカストディアルを意味しない

これは、OROKAIの設計における最も重要な区別の1つです。多くのユーザー（および規制当局）は、「ウォレットを作成する必要がない」ということは「OROKAIがあなたの資金を保有する」ことを意味すると考えるかもしれません。<mark>これは絶対に事実ではありません。</mark>

:::warning[簡素化されたセルフカストディ]

「ゼロセットアップ」は、OROKAIが鍵を保管することを意味しません。これは、セルフカストディモデルのままであるウォレット上の実用的な抽象化です。

:::

### 主な質問と回答

| 質問 | 回答 |
|----------|--------|
| **「OROKAIは私の資金を保有していますか？」** | **いいえ。**あなたの資金はあなたのアドレスのオンチェーンにあります。OROKAIはアクセスできません。 |
| **「OROKAIは私のアカウントを凍結できますか？」** | **部分的に。**UIアクセスをブロックできます（例：制裁措置のコンプライアンス）が、オンチェーン資金を凍結することはできません。常に他のウォレット経由でアクセス可能です。 |
| **「OROKAIがハッキングされたらどうなりますか？」** | **あなたの資金は安全です。**秘密鍵はあなたのデバイス上にあり、私たちのサーバー上にはありません。ハッカーはメタデータ（取引履歴）にのみアクセスでき、鍵にはアクセスできません。 |
| **「デバイスを紛失したらどうなりますか？」** | **ウォレットタイプによります。**スマートウォレット/MPC = メール/ソーシャル経由で回復可能。従来型 = シードフレーズのバックアップが必要。取引前に回復を有効にすることをお勧めします。 |
| **「OROKAIウォレットをMetaMaskで使用できますか？」** | **はい**（オプションCの場合）。シードフレーズをエクスポート → MetaMaskにインポート。スマートウォレット/MPCの場合、新しいMetaMaskアドレスに資金を転送します。 |
| **「OROKAIが閉鎖されたらどうなりますか？」** | **あなたの資金はアクセス可能なままです。**閉鎖前にウォレットをエクスポートするか、ブロックチェーンエクスプローラー+任意のウォレットソフトウェア経由で直接アクセスします。 |
| **「これは規制に準拠していますか？」** | **はい。**ノンカストディアルソフトウェアは、ほとんどの管轄区域（EU MiCA、シンガポールMAS、日本FSAを含む）で銀行/VASPライセンスを必要としません。私たちは顧客資金を保有していません。 |

### アクセスを失った場合の対処

シナリオ：ユーザーがOROKAIアプリの入った電話を紛失

オプションA/B（スマートウォレット/MPC）：
```
 1. ユーザーは新しいデバイスでorokaiにアクセス     
 2. 「デバイスを紛失しました」をクリック                                
 3. 本人確認：                                               
    ├─ メール認証コード                                      
    ├─ またはソーシャルログイン（Google/Apple）                              
    └─ または信頼できる連絡先の承認（設定されている場合）                  
 4. ウォレットへのアクセスが復元される                                        
 5. オプション：新しいデバイスを追加署名者として追加                   
                                                                   
 資金：安全（ブロックチェーン上に残る）                               
 アクセス：回復                                                
```

オプションC（従来型ウォレット）：
```
ユーザーがシードフレーズをバックアップしている場合：                     
 1. ユーザーは新しいデバイスでorok.aiにアクセス                  
 2. 「既存のウォレットをインポート」をクリック                         
 3. 12語のシードフレーズを入力                               
 4. アクセスが復元される                                         
                                                             
 ユーザーがシードフレーズをバックアップしていない場合：                           
 資金：永久に失われる（MetaMaskと同じ）                     
 これが、リカバリーオプションを有効にすることを推奨する理由             
```

OROKAIのアプローチ：
> 新規ユーザーにはデフォルトでオプションA/B（回復可能）

> バックアップ責任に関する明確な警告を表示

> 「今すぐバックアップ」プロンプトを提供（ただし強制しない）

> UXのシンプルさとセキュリティ教育のバランス
