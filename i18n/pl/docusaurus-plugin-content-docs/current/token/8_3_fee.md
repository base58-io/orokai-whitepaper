# Fee Economics (Gas) and Distribution (Epoch-Based)

## Fee Structure and Allocation

### Fee sources

> Gas for transactions on OROKAI Chain

> Protocol fees (e.g., batching, routing/indexing services, cross-chain messages)

### Distribution (example, to be set on-chain)

> X% → validators/delegators (epoch-based rewards)

> Y% → treasury (development, audits, grants)

> Z% → risk/operational fund

### Frequency

Epoch-based settlements (e.g., daily). Reward amounts are variable and not guaranteed, dependent on network activity and protocol parameters, among other factors.

### Transparency

On-chain dashboard and public parameter reports.

:::tip[Protocol-driven economics]

Fee distribution is governed by on-chain parameters, ensuring transparency and predictability in how network value is allocated.

:::
